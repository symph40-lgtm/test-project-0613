## 1. 15일로 판정할 수 있는 것과 없는 것 (v0.1 승계)

15일 ≈ 유효 표본 10~12밤. **측정 정확도**(translation_error, 연속값)와 **운영 무결성**은
판정 가능, **방향 엣지**(적중률·expectancy)는 판정 불가능(신뢰구간 ±30%p).
→ D+15 게이트 = "측정기가 정확한가 + 시스템이 도는가". "돈을 버는가"는 이후 게이트와 상시 루프.

## 2. 단계 게이트와 활성화 사다리 (v0.1 승계 + 킬스위치 연결)

- **G0→G1 (D+15)**: 가동률 ≥95%, 오차 중앙값 ≤ 오프라인 예측 1.5배, 룩어헤드 0건,
  σ 커버리지 방향 정상, 치명 결함 0건 → **G1B R1 조정 지시 실사용** (리스크 감소 기능 우선).
  불통과 시 수정 후 15일 리셋.
- **G1→G2 (D+30)**: 무사고 + 오차 중앙값 ≤0.45% + 가상 expectancy>0 → G1A T2 실진입 사이징 1/2.
- **G2→G3 (D+60)**: 원 스펙 합격 기준 전체 → 정상 사이징 + R2 잔차 트레이드. 판정 비대칭 유지.
- **G3 이후**: 롤링 90일로 G3 기준 매일 재계산. 30일 연속 미달 → G2 강등(자동).
  **킬스위치(신설)**: 직전 20거래밤 누적 손실이 한도(-6R 초기값) 초과 → **G0(log-only) 즉시 강등**,
  재상승은 게이트 절차 재이행. 리스크 감소 방향이므로 AI 자동 권한.

## 3. 계층 원리: 상태 / 파라미터 / 헌법

일간 학습을 안전하게 만들기 위한 핵심 구분. **무엇이 매일 변해도 되는가**를 계층으로 정의한다.

| 계층 | 정의 | 갱신 주기·주체 | 예 |
|---|---|---|---|
| **상태 (state)** | 시장을 따라가는 추정치. 매일 변하는 것이 정상이며, 변화 속도에 상한이 걸려 있음 | **매일 자동** (§4) | 칼만 β, EWMA σ, 편향 보정항, 앙상블 가중, 케이스 메모리 |
| **파라미터** | 시스템의 손잡이. 성능 근거로만 변경 | 주간 재추정 설정·월간 옵티마이저 + 게이트 (§5~6) | 임계 σ배수, θ(t), 사이징 매핑, 망각계수 자체 |
| **헌법** | 안전의 정의. 성능 근거로 변경 불가 | 인간만, 쿨다운 절차 (§5.3) | abstain 규칙, 사이징 상한, 물타기 금지, 피처 동결, σ 추정 설정, λ·μ |

원리: **상태는 빨리 배우고, 파라미터는 천천히 바뀌고, 헌법은 거의 바뀌지 않는다.**
일간 학습이 안전한 이유는 학습 대상이 상태 계층에 갇혀 있고, 각 상태의 학습 속도(게인·망각계수)가
파라미터 계층에 있으며, 그 상하한이 헌법 계층에 있기 때문이다 — 3계층이 서로를 물고 있다.

## 4. 일간 학습 알고리즘 (신설 — 매일의 학습·추론·검증)

매일 밤 하나가 표본 하나다. 다음 다섯 개의 상태가 매일 갱신된다. 공통 원칙:
**모든 일간 예측은 구조상 아웃오브샘플이다** (오늘 예측은 어제까지의 상태로만 생성, 오늘 라벨로 내일 상태 갱신).

### 4.1 β의 온라인 갱신 — 칼만 필터 (주간 배치 OLS 대체)

```
상태방정식: β_t = β_{t-1} + η_t,  η_t ~ N(0, Q)        [β는 천천히 표류한다]
관측방정식: gap_t = x_t'β_t + ε_t, ε_t ~ N(0, σ²_night)
매일: 예측 → 실측 gap 관측 → 칼만 갱신 (채널별: 지수 b, 고유 c, β_mkt 각각)
```
- 효과: 레짐 전환(예: 하닉 SOX 디커플링)을 주 1회 배치보다 수 일 빨리 추적. Q가 클수록 빨리
  배우고 과민해진다 — **Q는 파라미터 계층**(월간 최적화 대상), **Q의 상한은 헌법**
  (일일 β 변화 ≤ 정상 표준오차의 0.5배로 클램프 → 하룻밤 이상치가 β를 납치하지 못함).
- 주간 배치 OLS는 폐지하지 않고 **감사용 병행**: 칼만 β와 배치 β의 괴리 > 2 표준오차 시
  플래그 (온라인 갱신의 폭주 감지).

### 4.2 σ의 일간 갱신 — EWMA 변동성 (GARCH-lite)

```
σ²_night(t+1) = λ_σ·σ²_night(t) + (1−λ_σ)·resid_t²     [레짐별 분리 유지]
```
- λ_σ 초기 0.94. λ_σ는 파라미터 계층이되 **하한 0.90 헌법 고정** — 옵티마이저가 σ를 과민하게
  만들어 임계 체계를 흔드는 경로 차단 (§5.1의 "자의 눈금" 봉쇄와 한 쌍).
- 매일 산출되는 σ로 다음 밤의 모든 σ 기준 판정이 이뤄진다 — 주간 갱신 대비 이벤트 직후
  주간의 임계값 왜곡이 사라진다.

### 4.3 편향 보정항 — 잔차의 계통 성분 흡수

```
bias_t = λ_b·bias_{t-1} + (1−λ_b)·resid_t,   FairGap에 −bias_t 가산
클램프: |bias_t| ≤ 0.3×σ_night (헌법)
```
- 최근 오차가 계통적으로 한 방향이면(모델이 놓치는 완만한 국면 요인) 이를 흡수하는 1차 자기수정.
- 클램프의 이유: bias가 커진다는 것은 보정이 아니라 **모델 붕괴의 증상**이다 — 상한 도달 시
  보정을 늘리는 게 아니라 건강 경보(§8)로 넘긴다. 자기수정과 자기기만의 경계선.

### 4.4 앙상블 결합 가중 — 온라인 전문가 학습 (Hedge/지수가중)

FairGap을 만드는 예측원(전문가)들 — {채널 회귀(칼만), 관측부(야간선물·GDR·시간외),
케이스 메모리(§4.5), (G3 이후) ML 챌린저} — 의 결합 가중을 매일 갱신한다.

```
w_i(t+1) ∝ w_i(t) · exp(−η_H · loss_i(t)),   loss = |전문가 예측 − 실측 gap| / σ_night
제약: 학습률 η_H 상한(헌법), 단일 전문가 가중 상한 0.7(헌법), 레짐별 분리 가중
```
- v0.1의 "월간 격자 탐색으로 u·v·w_reg 역산"을 대체·흡수한다 — 결합 가중은 이제 매일
  후회최소화(regret-bound) 방식으로 배운다. 이론적 근거: 온라인 전문가 학습은 최선의 고정
  가중 대비 성능 격차가 표본수에 따라 수렴함이 보장된다 (과최적화가 구조적으로 제한됨).
- 월간 옵티마이저의 역할은 가중 자체가 아니라 **η_H·λ들·임계 σ배수 등 파라미터**로 이동.

### 4.5 케이스 메모리 — Q1 연동 유사 밤 검색

```
매일: 그 밤의 특징 벡터(레짐, SurpriseZ, 채널 신호, σ, 요일, 이벤트 태그)와 실측 잔차를 메모리에 적재
추론: 오늘 밤과 유사한 과거 k=15밤 검색 → 그 잔차 분포의 중앙값 = 케이스 전문가의 예측 보정
```
- 회귀가 못 담는 비선형·조건부 패턴("이런 종류의 밤엔 모델이 늘 과소평가했다")을 비모수로 흡수.
- 표본 30밤 미만에서는 가중 0에서 시작 — §4.4의 Hedge가 실적을 보고 자연히 가중을 키운다
  (신규 전문가의 진입 규칙: 무실적 전문가는 무가중).

### 4.6 일간 검증 — 매일 아침의 성적표

- **PIT 캘리브레이션**: 매일 실측 gap의 예측분포 내 분위수(PIT 값)를 기록. 롤링 60밤 PIT가
  균등분포에서 이탈(KS 검정)하면 σ 체계 재점검 — "맞췄나"만이 아니라 **"불확실성 추정이
  정직했나"** 를 매일 채점한다.
- **CUSUM 드리프트 감지**: 잔차의 누적합 관리도 — H지표(5일 MAE, 크기 변화 감지)와 상보적으로
  **부호 편향의 조기 감지** 담당. 발동 시 건강 경보와 동일 조치.
- 전문가별 일간 loss 리더보드: 어느 예측원이 최근 시장을 잘 읽는지 매일 갱신·리포트 병기.

## 5. 최적화 대상의 3분류 (침식 우회로 봉쇄)

### 5.1 분류표

**자유 파라미터 (양방향 최적화 허용):** 바스켓 구성비, 케이스 메모리 k, 리포트 포맷 관련,
θ(t)의 세부 스케줄 형태 (단 단조성 제약 하에서).

**편측 제약 파라미터 (안전 방향으로만 바닥/천장 — 옵티마이저는 범위 내에서만):**
| 파라미터 | 제약 | 봉쇄 목적 |
|---|---|---|
| 잔차 발동 σ배수 | **≥ 1.0σ** | 과잉거래 방향 침식 |
| 오판 확정 σ배수 | ≤ −0.4σ (더 둔감하게 못 만듦) | 손절 지연 방향 침식 |
| w_reg(이벤트 밤) | **≤ 0.3** | "이벤트 밤 회귀 불신" 안전 규칙의 수치 침식 |
| θ_early | **≥ θ_final** (단조 감소 유지) | 조기 진입 문턱 평탄화 |
| DC-PM 기준 | ≥ 55% | 확인 없는 진입 |
| 칼만 Q, η_H, λ_b | 상한 고정 | 학습 속도 폭주 |
| λ_σ | **하한 0.90** | σ 과민화("자의 눈금") |

**헌법 (옵티마이저 접근 차단 + 인간도 §5.3 절차로만):**
abstain 안전 규칙 전체 / 사이징 절대 상한(1/3, 합산 1/3)·물타기 금지·레버리지 오버나이트 금지 /
피처 동결 / luck 분류·판정 비대칭 / **σ 추정 설정(레짐 분류 기준·윈도 구조)** /
**목적함수 리스크 계수 λ·μ** (v0.1 미해결 → 헌법 확정 편입: λ=0.5, μ=0.2) /
상태 클램프 상한 일체 / 킬스위치 한도.

### 5.2 목적함수 (확정)

```
J = expectancy(롤링 90일 OOS) − 0.5·MDD추정 − 0.2·회전비용    [계수는 헌법]
```

### 5.3 헌법 변경 절차 (인간 경로 봉쇄)

1. **2단 승인 + 쿨다운**: 개정 제안 기록 → **7일 경과** → 재확인 서명 시에만 발효.
   (드로다운의 한복판에서 헌법을 고치고 싶어지는 것은 옵티마이저가 아니라 인간이다.)
2. **드로다운 동결**: 직전 20거래밤 손실이 킬스위치 한도의 절반 초과 시, **완화 방향** 개정 동결
   (강화 방향은 즉시 가능 — 비대칭 권한 원칙의 헌법 적용).
3. 모든 개정은 변경 로그 + 사유 + 당시 성과 스냅샷 필수 (사후 감사 가능성).

## 6. 챔피언–챌린저 (심사·승격·롤백 개정)

### 6.1 구조 (승계)
챔피언 pack 실사용, 챌린저 최대 2개 섀도 병행. 옵티마이저는 베이지안 탐색, 시도 전량 로깅.

### 6.2 승격 심사 (개정 — 서사가 아니라 메커니즘을 심사한다)

1. **가설 사전 등록**: 챌린저 생성 시점에 "무엇이 왜 좋아지는가"를 **검증 가능한 형태**로 등록.
   예: "잔차 임계 1.2→1.35σ 상향으로 저σ밤 거래 30% 감소, 저σ밤 손실 기여 축소".
2. **메커니즘 실현 심사**: 섀도 종료 후 총성과가 아니라 **등록 가설의 실현 여부**를 먼저 확인.
   총성과가 좋아도 메커니즘 불일치면 기각 (우연 개선 = 과최적화 추정). LLM의 역할은 사유
   작문이 아니라 등록 가설 대비 실현 여부의 **판정 보고서** 작성으로 한정.
3. **최소 마진 + 시도 페널티**: 승격 요건 = 챔피언 대비 expectancy 우위 ≥ m(n),
   m(n) = m₀·(1 + 0.15·log(1+n)), n = 누적 챌린저 시도 수. 많이 시도할수록 문턱이 오른다
   (승자의 저주 보정). 추가 요건: 섀도 전·후반 성과 부호 일관, 최악 밤 비악화.
4. 섀도 기간은 **거래밤 기준 ≥ 12거래밤** (달력 15일 아님 — abstain 많은 구간 표본 부족 방지).

### 6.3 롤백 (개정 — 동시 반사실 비교)

- 승격 시 **구 챔피언을 거울 섀도로 계속 가동** (챌린저였을 때의 역할 교대).
- 롤백 판정: 승격 후 **10거래밤** 내에 신챔피언 성과가 **거울 섀도(구 챔피언) 대비** 유의 열위
  → 자동 복원. 시장 전체가 붕괴한 구간에서 신챔피언만 처벌하는 오판을 반사실 비교로 제거.
- 거울 섀도는 승격 후 30거래밤까지 유지 후 해제.
