## 1. 2층 국면 기계

### 1.1 국면 판별층 (S1~S4, 확률)

```
S1 바닥권(하락→횡보) / S2 상승 추세 / S3 천장권(상승→횡보) / S4 하락 추세
```

**출처 주석**: Hamilton(1989) 국면전환 모형의 *규칙 기반 근사*. 완전 마르코프 추정(EM·필터링)은 국면당 표본 요구가 과다(3년 = 국면당 수십 일)하여 채택하지 않는다 — 발주서 §1.1 명시. 4국면 구획 자체는 Weinstein Stage 1~4·Wyckoff 4국면(축적/상승/분산/하락)과 동일한 골격이다.

**입력 (발주서 §1.1: 20일 기울기 × 변동성 수축·확장 × 저점/고점 갱신)**

| 기호 | 정의 |
|---|---|
| `slope20` | 최근 20일 종가의 OLS 기울기 × 20 ÷ 최신 종가 × 100 (= 20일간 추세가 만든 % 변화) |
| `z` | `clamp(slope20 / RV_20d20, −3, +3)` — 추세를 잡음으로 나눈 표준화값. `RV_20d20` = 20일 실현변동성을 20거래일 지평으로 환산(`RV_20/√252×√20`) |
| `flat` | `1 − min(1, |z| / 1.0)` — 추세 없음의 정도 |
| `squeeze` | `RV_20 / RV_60` (<0.85 수축 · >1.20 확장) |
| `hh10` | 최근 10일 내 20일 신고가 발생 = 1 |
| `ll10` | 최근 10일 내 20일 신저가 발생 = 1 |
| `pos60` | `(close − min60) / (max60 − min60)` |
| `r60` | 60일 수익률 % (직전 국면의 방향 = 사전확률 역할) |

**국면 점수 → 확률**

```
score_S2 = 1.2·max(z,0)  + 0.8·hh10 + 0.4·(2·pos60 − 1)
score_S4 = 1.2·max(−z,0) + 0.8·ll10 + 0.4·(1 − 2·pos60)
score_S1 = 1.0·flat + 0.8·min(1, max(0,−r60)/10) + 0.6·(1 − ll10) + 0.4·[squeeze < 0.85]
score_S3 = 1.0·flat + 0.8·min(1, max(0, r60)/10) + 0.6·(1 − hh10) + 0.4·[squeeze < 0.85]
P(S_k) = softmax(score_k / τ),  τ = 0.5   (등록 상수)
```

- S1·S3의 `flat`·`(1−ll10)`·`(1−hh10)`은 "추세가 멈췄고 갱신이 끊겼다"는 횡보 조건, `r60` 항은 **직전에 무엇이었나**(하락 뒤 횡보 = 바닥권 / 상승 뒤 횡보 = 천장권)를 가른다.
- 확률은 소수 2자리로 표시하고 **최상위 국면만 단정하지 않는다** (예: "S1 70%·S2 25%").

### 1.2 국면별 전용 패널

각 부품은 **0~1 연속 충족도 `fill`** 을 낸다 (발주자 보충 §1.4-1a). 화면에는 `이름 fill — 충족/미충족` 형식으로 병기한다.

#### S1 바닥권 — "봄으로 넘어가는가" (4부품)

| ① | 악재 무반응 | 최근 10일의 **악재일**(C1 재료 방향 < 0) 반응배율 중앙값 `m`에 대해 `fill = clamp((0.8 − m)/0.8, 0, 1)` — 반응이 정당화분의 0에 가까울수록 1 | Veronesi(1999): 나쁜 소식에 둔감해지는 국면 = 정보의 가격 반영이 이미 끝난 상태 |

### 1.4 전환 선언 — 투표 (발주자 보충 §1.4-1b: 역할 분리) — **동결**

> **MT 톤 값 = 연속 가중합** (게이트·내성 판정용) / **국면 전환 선언 = 투표** (2/3, 4부품 패널은 3/4). 두 경로는 서로를 참조하지 않는다.

```
vote_k   = #{부품 i ∈ 패널 k : fill_i ≥ 0.6}          # 발주자 보충 §1.4-1a
정원 문턱 = 3부품 패널 → 2표 / 4부품 패널 → 3표
"전환 후보" = vote_k ≥ 문턱
"전환 확정" = 후보 + 가격 확인 (박스 상단 돌파 / 하단 이탈, 박스는 §3.3 자동 산출)
```

**결측 축소 규칙**: 가용 부품이 정원보다 적으면 문턱 = `가용 4 → 3 / 가용 3 → 2 / 가용 2 → 2(전원) / 가용 ≤1 → 판정 유보`. 유보 시 국면 전환은 선언하지 않고 화면에 "부품 부족 — 판정 유보"를 표시한다.

**후보 유지창 (등록 상수 `confirmWindow = 10`거래일 — 2026-08-15 추가, 승인 요청 사항)**
"후보 + 가격 확인"에서 **둘이 같은 날일 필요는 없다**. 증거가 먼저 쌓이고 가격이 뒤늦게 확인하는 것이 정상 순서다. 최근 10거래일 안에 같은 방향의 패널 후보가 섰고 오늘 가격 확인이 오면 확정으로 본다.
- 근거(실측): 동일일만 인정하면 3년 소급에서 확정이 **3종목 합계 4건** — 후보일 8% × 가격 확인일 1.5%의 교집합이라 사실상 작동 불능이었다 (`docs/mt-retro-3y.md` §1 vs §1-1).
- 창 = 0으로 두면 원 구현(동일일 전용)과 같다. 라이브도 최근 30일을 계산해 같은 함수를 통과시켜 **소급과 값이 갈리지 않게** 한다.

**가중과 투표의 분리 (코드 수준 보장)**: §4.2가 재배분하는 부품 가중은 **연속 가중합(톤) 경로에만** 적용된다. 투표는 가중과 무관하게 **1부품 1표**다.

## 2. C1 반응비대칭 — 등급 체계 (발주자 승인 2026-08-15)

```
반응배율 = 실반응 ÷ 정당화 반응
  실반응     = 당일 대상 종목/지수 수익률 %
  정당화 반응 = 재료 크기 × 민감도(β)
```

| 등급 | 재료 방향·크기의 출처 | 정당화 반응 | 가용 구간 |
|---|---|---|---|
| **A** | 컨센서스·서프라이즈 **수동 입력** | 서프라이즈 × 민감도 | 입력일만 |
| **B** | `predict_case_days.cause_tags` 부호 (호재/악재 태그) | `β_SOX × 전일밤 SOX 수익률` | 2026-07-29~ |
| **C** | **전일밤 ^SOX 수익률의 부호·크기** | `β_SOX × 전일밤 SOX 수익률` | 2023-01-03~ 전 구간 |

- `β_SOX`는 60일 롤링 회귀(대상 일간수익률 ~ 전일밤 SOX 일간수익률)로 매일 갱신, 하한 0.3·상한 3.0으로 절단(등록 상수). 회귀 표본 40일 미만이면 G1B pack 초기값 준용.
- **정당화 반응이 0에 가까우면 배율이 발산**한다 → `|정당화 반응| < 0.3%` 인 날은 **재료 없는 날**로 분류하고 C1 산출에서 제외한다(등록 상수, 오분류 방지).
- 남는 극단값은 **반응배율 ±5 윈저화**(등록 상수 `ratioClip`)로 자른다. 원값은 `note`에 남긴다 — 중앙값·화면 표시가 분모 작은 하루에 끌려가지 않게 하기 위함.
- 등급은 화면·로그에 **항상 병기**한다. 등급별 **오분류율**(재료 방향 판별이 이후 실현 방향과 어긋난 비율)을 매일 기록한다 (발주서 §3.1).

### 2.1 승인 조건 3건 (발주자 보충)

1. **§4.1ⓓ 관문은 두 벌 보고** — ⑴ 전체(A+B+C) ⑵ A+B만. 두 벌이 갈리면 관문 통과 판정은 **A+B 벌을 우선**하고 차이를 명시한다.
2. **A-C 일치율 실측** — A등급이 존재하는 날에 C 프록시를 **병렬 산출**해 재료 방향 일치율·배율 상관을 낸다. 이것이 C등급의 신뢰도 수치다. *현재 A등급 표본은 0일(컨센서스 미입력)* 이므로 **B-C 일치율을 대리 보고**하고, A 입력이 생기는 즉시 A-C가 자동 산출되도록 구현한다.
3. **등급 구성비 병기** — 모든 소급 채점표에 A/B/C 비율(%)을 함께 싣는다.

## 3. 산출·표시

### 3.1 MT 종합값

```
tone_k = inertia_k + evidence_k × fill_k     (fill_k = 패널 k 부품 fill의 가중평균 — 가중은 §4.2)
MT = clamp( Σ_k P(S_k) × tone_k , −1, +1 )
```

| 국면 | `inertia` | `evidence` | 읽는 법 |
|---|---|---|---|
| S1 | 0 | **+0.7** | 봄 전환 증거가 쌓일수록 상승 에너지 |
| S2 | **+0.3** | +0.7 | 추세 자체가 상승(+0.3), 건강할수록 가산 |
| S3 | 0 | **−0.7** | 분산 증거가 쌓일수록 하락 에너지 |
| S4 | **−0.3** | +0.7 | 추세 자체가 하락(−0.3), 투매 종결 증거가 쌓이면 상쇄·반전 |

(등록 상수. 변경은 §4.2 월간 재캘리브레이션 절차로만.)

**라벨**: 방향 = `MT > 0` 상승 에너지 / `< 0` 하락 에너지. 강도 = `|MT| < 0.2` 약 · `0.2~0.5` 중 · `≥ 0.5` 강.

### 3.2 표시 형식 (T2·R1 카드 상시 줄)

```
MT: S1 바닥권 70% → S2 시도 중 | 패널 [확인일 1.00 ✓ · No Supply 0.55 ✗ · 박스돌파 0.42 ✗ · 악재무반응 0.71 ✓]
    | 톤 +0.5 상승 에너지·중 | 박스 268,000~281,500 (위치 61%)
```

- 부품은 **충족도 수치를 항상 병기**(발주자 보충 §1.4-1a). ✓ = `fill ≥ 0.6`.
- 보조 플래그: `악재 무반응 감지` / `확인일 발생` / `가짜 돌파` / `Spring` — **발생 시에만** 표시.
- 1단계는 **판정 무개입**이다 (검증 오염 없음).

### 3.3 박스 자동 산출

```
box_high = max(high, 최근 N일) / box_low = min(low, 최근 N일),  N ∈ {20, 60}
유효 조건: (box_high − box_low) / close ≤ 0.15  (20일) / ≤ 0.30 (60일)
둘 다 유효하면 20일 박스를 주(主)로, 60일은 병기 (Weinstein 축소판 병용 지시)
무효면 "박스 없음(추세 구간)"으로 표시하고 §1.4 가격 확인은 20일 고·저가로 대체
```

- **돌파 판정의 기준선은 전일까지의 박스**다. 당일 고가를 포함해 재면 `종가 ≤ 당일 고가 ≤ 박스 상단`이라 돌파가 원리상 성립하지 않는다 (2026-08-15 검산에서 교정). 화면 표시용 박스는 당일 포함 유지.
- **실측 경고 (2026-08-15)**: 최근 60일 구간에서 박스 유효율이 **3종목 모두 0%** 였다 (20일 폭 삼전 31.6%·하닉 46.2%·K200 29.6%). 3년 기준으로는 삼전 66%·하닉 39%·K200 83%. 즉 현 변동성 국면에서만 고정 문턱이 무력하다. 변동성 상대 문턱(예: 20일 폭 ≤ 2.5 × RV20의 20일 환산)으로 바꾸는 안은 **등록 상수 변경이라 발주자 승인 대기** (`docs/mt-backfill-60d.md` 발주자 결정 요청 1번).

## 4. 채점과 자기교정 (MT-OPT — G1-OPT 3계층 이식)

### 4.1 일일 채점 라벨 3종 (상태 계층)

1. **방향 라벨** — `sign(MT)` vs 이후 5거래일 시장 수익률 부호 (`|수익률| < 0.5%`는 무방향 처리)
2. **게이트 라벨 (주 성적표)** — T2 방향과 MT 부호가 **일치한 밤** vs **충돌한 밤**의 갭 적중률 차. **승격 심사의 1지표**
3. **내성 라벨** — 이벤트·악재일에 MT 부호별 실현 반응 크기(|갭|·|일중 진폭|)
- C1 재료 판별 **오분류율**을 등급별로 병기 (§2.1-3)

### 4.2 월간 재캘리브레이션 (파라미터 계층)

- 부품별 **IC**(부품 fill 단독 vs 라벨의 순위상관) 산출 → 가중 재배분
- 제약: **1회 변경폭 ≤ 30%** · `|IC| < 0.05` 부품은 **가중 0 강등**(기록은 지속) · 변경 가중은 **15일 섀도 병행 후** 교체
- **부품 간 상관 모니터링** (발주자 보충 §1.4-3): 패널 내 부품 **쌍 상관 > 0.7이 2개월 연속** 지속되면 보고한다 — 사실상 1표가 2표 행세하는 **이중계상** 감지. 보고까지가 이 스펙의 범위이며, 통합·제거는 발주자 승인 사항.

### 4.3 헌법 (불변)

- MT **단독 방향 베팅 금지** — 게이트·내성 판정 전용
- **부품 수 동결**, 게이트 배율 상한 (연동 시 ×0.5 ~ ×1.25)
- MT는 **후행·관성 지표**임을 문서·화면에 명기 (전환점 예언 불가, 증거 집계만)
