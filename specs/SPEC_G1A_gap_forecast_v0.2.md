# SPEC — G1A: 전일 갭 예측 모듈 (Gap Forecast, 문제 A)

- 문서 버전: v0.2 (가중치 체계 개정판 — 대화 기록 기반 복원본)
- 상태: 설계 단계 → **log-only 60일** 검증 후 활성화 (StockGuard 신규 시그널 프로토콜 준수)
- 대상 종목: 삼성전자(005930), SK하이닉스(000660) — 현물 기준
- 관련 모듈: DC1/DC2, N1, O1, W1, V1, B1, C1, Q1 / 후속 모듈: G1B(야간 번역)

---

## 1. 목적

D일(당일) **미국 세션 결과를 알 수 없는 시점**에, D+1일 시가 갭의 방향과 크기를 판정하고,
판정 시점에 즉시 실행 가능한 리포트(문자)를 발행한다.

- 이 모듈은 "진짜 예측"이다. 목표 적중률은 55~58% 수준을 상한으로 가정하고,
  수익은 적중률이 아니라 **판정 보류(abstain) 규율 + 사이징 + 비대칭 페이오프**에서 나온다.
- 예측 대상은 정보가 아니라 **판정 시점까지 관측 가능한 데이터의 추세**다.
  판정 이후 밤사이 뉴스는 원천적으로 알 수 없음을 전제한다 (G1B가 이어받는다).

## 2. 판정 시점 (두 개의 체크포인트)

| 코드 | 판정 데드라인 | 실행 창구 | 사용 가능 정보의 경계 |
|---|---|---|---|
| **T1** | 15:10 KST | KRX 정규장 (~15:30 동시호가) | 국내 정규장 전체 + 아시아 세션 글로벌 데이터 |
| **T2** | 19:40 KST | NXT 애프터마켓 (~20:00) | T1 + 유럽장 개장 반응 + 미국 프리마켓 초반(≈18:00 KST~) |

- T1과 T2는 **독립된 두 번의 판정**이다. T2는 T1 판정을 승계·수정·취소할 수 있다.
- T2에서 방향이 뒤집히면: T1 포지션은 애프터마켓에서 축소/청산. "T1이 맞았어야 한다"는 앵커링 금지.
- 리포트 발송: T1 리포트 15:10, T2 리포트 19:40 (판정 근거 요약 포함, §8 템플릿).

## 3. 라벨 정의 (예측 대상)

주 라벨과 보조 라벨을 분리한다. **로그에는 셋 다 기록**하되 G1A의 평가는 L1 기준.

| 라벨 | 정의 | 용도 |
|---|---|---|
| **L1 (주)** | D일 KRX 정규장 종가 → D+1일 KRX 정규장 시가 수익률 | G1A 평가 기준 |
| L2 (보조) | D일 종가 → D+1일 NXT 프리마켓 첫 체결가 | 프리장 실행 검증용 |
| L3 (보조) | D+1일 시가 → 시가+30분 수익률 | G1B 잔차 트레이드 검증용 (G1A에선 기록만) |

- 방향 분류: UP (L1 ≥ +0.3%), DOWN (L1 ≤ −0.3%), FLAT (그 사이). ±0.3%는 초기값, 60일 로그로 재조정.
- 크기 구간: S(0.3~0.8%), M(0.8~1.5%), L(1.5%+) — 크기 예측은 방향과 별도로 기록.

## 5. 판정 로직

기존 이축 모델을 그대로 확장한다: **Bias축(방향) × Confirmation축(질) → GapScore → 판정**.

### 5.1 GapScore — 인과 계층 가중 체계 (v0.2 개정)

#### 5.1.0 설계 원리 (가중치 부여의 3원칙)

가중치는 임의 배점이 아니라 다음 세 기준의 곱으로 정한다.

1. **라벨과의 인과 거리**: D+1 시가는 "밤사이 미국 세션"이 직접 결정한다. 따라서
   미국 세션의 근접 대리(TSMC, 미 선물, 프리마켓)일수록 가중이 크고,
   인과 사슬 상류(금리→달러→환율→외인)로 갈수록 가중이 작다.
2. **이중계상 금지**: 금리·달러·환율·외인은 **같은 전달 사슬 위의 변수**다.
   같은 밤 셋이 동시에 같은 방향을 가리키는 것은 독립 증거 3개가 아니라 증거 1개의 세 번 관측이다.
   → 사슬 단위 그룹 캡으로 강제 차단.
3. **레벨이 아니라 서프라이즈**: 금리 수준이 데이터센터 투자를 좌우하는 것은
   수주~수개월 채널(Bias축 담당)이지 하룻밤 갭 채널이 아니다. G1A에 들어가는 매크로 변수는
   전부 **당일 변화의 z-score**(20일 기준)로 표준화한다. 레벨·추세는 T-score/Bias 체계에 남긴다.

#### 5.1.1 이층 구조: 게이트 × 가산

```
GapScore = BiasGate × Σ w_i · s_i

s_i : 각 피처의 표준화 신호, [−1, +1] 클리핑 (연속 피처는 20일 z-score → tanh)
BiasGate ∈ {0.5, 1.0, 1.25}
```

**BiasGate (매크로 상류의 역할)** — 금리·환율은 점수를 "더하는" 변수가 아니라
하류 신호의 **신뢰도를 조절하는 승수**로 쓴다. 이것이 기존 룰 계층
("매크로 필터가 인트라데이 시그널에 우선")의 점수화 버전이다.

| 조건 | Gate |
|---|---|
| 매크로 사슬 합성 방향(F13+F14, 감쇠 z 합)이 가산부 Σ와 **일치** | 1.25 |
| 매크로 사슬이 중립 (\|합성 z\| < 0.5) | 1.00 |
| 매크로 사슬이 가산부 Σ와 **충돌** (예: 하류는 UP인데 2Y 급등+원화 급락) | 0.50 |

#### 5.1.2 가산부 초기 가중치 표 (T1 / T2)

| 계층 | 피처 | w (T1) | w (T2) | 근거 |
|---|---|---|---|---|
| **L1 근접대리** | F11 TSMC 당일 확정 | 1.5 | 1.0 | 동일 사이클 최강 동행, T1 유일의 "확정치" |
| | F10 미 선물 아시아 | 1.0 | — | T2에서 F22로 대체 |
| | F22 미 선물 유럽 세션 | — | 1.0 | F10 갱신치 |
| | F21 미 프리마켓 반도체 | — | **2.0** | T2 최중요 — 라벨과 인과 거리 최단 |
| | F20 유럽장 개장 톤 | — | 0.5 | |
| | F23 NXT 저녁 흐름 | — | 0.5 | |
| **L2 당일 캐릭터** | F01 CLV | 1.0 | 0.75 | 추세일 갭 지속 통계 |
| | F02 DC1 | 0.75 | 0.5 | 확인축 |
| | F04 O1 오픈타입 | 0.5 | 0.25 | |
| | F09 C1 | −0.25 | −0.25 | 종가 왜곡의 **역방향 보정** (리밸런싱 방향만큼 차감) |
| **L3 수급** | F08 외인 감속률 | 0.75 | 0.5 | |
| | F05 W1 | 0.5 | 0.25 | |
| | F07 B1 | 0.5 | 0.25 | |
| **L4 매크로 서프라이즈** | F13 금리 당일 Δz | 0.5 | 0.5 | 가산은 소액 — 주 역할은 BiasGate |
| | F14 달러/환율 Δz | 0.5 | 0.5 | 〃 |
| | F24 저녁 뉴스 | — | ±1 상한 | 수동 판정, Q1 태그 필수 |

**그룹 캡 (이중계상 차단):**
- 매크로 사슬 (F13+F14 가산분): 합산 상한 **±1.0** — 둘 다 극단이어도 1.0 초과 불가
- 수급 계층 (F05·F07·F08): 합산 상한 ±1.5 — 외인·베이시스·폭은 같은 플로우의 세 단면
- 근접대리 계층: T1 상한 ±2.5 / T2 상한 ±3.5
- 당일 캐릭터: 상한 ±2.0

**방향 점수에서 제외되는 피처 (역할 재지정):**
- F03 (N1/NR7): 방향 정보 없음 → **크기 예측 전용** (§3 크기 구간 S/M/L 상향 조정자)
- F06 (V1), F16 (implied move): 크기·레짐 조정자
- F15, F17: §5.3 abstain·사이징 강등 전용 (가산 금지)
- F18 (Q1): 활성화 후 w=0.5로 편입 예정

T2 만점은 T1보다 크다 (근접대리 정보가 많으므로). 판정 테이블(§5.2)의 임계값은
**T1: ±2 / ±4, T2: ±2.5 / ±5** 로 분리 적용한다.

#### 5.1.3 가중치 캘리브레이션 프로토콜 (60일 로그 이후)

초기 가중치는 사전 신념(prior)이다. 다음 절차로 데이터가 이를 덮어쓴다.

1. **1단계 (30일차)**: 피처별 IC 산출 — s_i와 L1 방향의 point-biserial 상관.
   \|IC\| < 0.05인 피처는 shadow weight 0으로 강등 (로그에는 계속 기록).
2. **2단계 (60일차)**: 표준화 로지스틱 회귀 (L2 정규화, 라벨=L1 방향)의 계수 비율로
   w 재배분. 단 **그룹 캡과 계층 순서(L1>L2>L3>L4)는 회귀 결과와 무관하게 유지** —
   60일 표본으로 인과 구조를 뒤집지 않는다 (과최적화 방지).
3. **재조정 주기**: 이후 30일마다. 변경된 가중치는 **shadow 모드로 15일 병행 기록** 후 교체
   (신규 시그널 프로토콜의 축소판).
4. **최종 단계**: ML 통합 시 s_i 전체를 Rule-as-Feature로 LightGBM에 주입,
   SHAP로 본 가중표와 대조. GapScore는 해석 가능한 그림자 모델로 존치.

### 5.2 판정 테이블 (임계값 θ1/θ2는 시점별 분리: T1 = 2/4, T2 = 2.5/5)

| 조건 | 판정 | 권장 사이징 |
|---|---|---|
| GapScore ≥ +θ2 이고 F02(DC1) 상방 확인 | **UP / High** | 1/3 |
| +θ1 ≤ GapScore < +θ2 | UP / Low | 1/6 |
| −θ1 < GapScore < +θ1 | **NEUTRAL — 노포지션** | 0 |
| −θ2 < GapScore ≤ −θ1 | DOWN / Low | 1/6 |
| GapScore ≤ −θ2 이고 DC1 하방 확인 | DOWN / High | 1/3 |

- BiasGate 0.5(매크로 충돌)가 걸리면 High 등급은 구조적으로 거의 도달 불가 — 의도된 설계다.
  매크로가 반대를 가리키는 밤의 갭 베팅은 Low 이하로만 허용된다.

### 5.3 판정 보류 (abstain) — 점수보다 우선하는 상위 규칙

기존 룰 계층("매크로 필터·이벤트 제한이 인트라데이 시그널에 우선") 승계:

1. **F15 바이너리 이벤트 밤** (FOMC, CPI, 대형 실적) → 무조건 NEUTRAL. F16 implied move가 1.5×평상시 이상이면 실적 외 이벤트도 동일.
2. **금요일 (주말 보유 금지 규칙)** → NEUTRAL.
3. F17 포지셔닝 극단 + GapScore가 뉴스 방향과 동일 → 사이징 1단계 강등 (sell-the-news 리스크).
4. KOSPI 서킷브레이커 발동일 → 당일·익일 NEUTRAL, Q1 케이스 기록만.
5. 데이터 결측(핵심 피처 2개 이상) → NEUTRAL.

**Abstain은 실패가 아니라 이 모듈의 주 수익원이다.** 로그에 abstain 사유를 반드시 기록.
