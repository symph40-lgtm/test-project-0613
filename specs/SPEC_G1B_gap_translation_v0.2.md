## 1. 목적

미장 마감 후 ~ 국장 개장 전에 축적되는 **모든 가용 정량·정성 정보**를 하나의 예상 갭으로 종합하여:

1. **FairGap(공정 갭)과 ExpectedOpen(예상 시가)** 을 산출·갱신하고 (R1 → R2 2단 갱신),
2. G1A 포지션의 조정 지시(추가/유지/후퇴/반전)를 내리며,
3. 실제 시가의 잔차(미스프라이싱)를 판정해 시가 부근 트레이드 신호를 낸다.

원칙: **정보의 시장가격 반영분과 미반영분을 구분한다.** 이미 가격에 반영된 정보를 변수로
중복 투입하는 것(이중계상)이 이 모듈의 제1 오류원이므로, 모든 신규 변수는
"어떤 가격에도 아직 반영되지 않은 성분인가"를 통과해야 편입된다 (§5의 이벤트 처리가 대표 사례).

## 3. FairGap 3층 구조 — 종합 관계식

### 3.0 전체 골격

```
FairGap_R1 = w_reg(레짐) · FairGap_reg  +  (1 − w_reg(레짐)) · Obs_R1  +  δ_event + δ_manual
FairGap_R2 = FairGap_R1 + ΔAsia + ΔGlobex2                            (아침 갱신)
ExpectedOpen_Rk = D일 KRX 종가 × (1 + FairGap_Rk)
```

세 층의 역할: **Layer 1(회귀)** 은 평상시 관계의 기대값, **Layer 2(관측)** 는 시장이 실제로
매기고 있는 가격, **Layer 3(오버레이)** 는 어떤 가격에도 아직 반영되지 않은 정보의 수동 보정.

### 3.1 Layer 1 — 정량 회귀 (확장)

```
FairGap_reg = α + β1·r_SOXX                     [핵심 — 미국 반도체 세션]
                + β2·r_peer_orth                 [MU/NVDA의 SOXX 직교 잔차]
                + β3·Δfx_orth                    [NDF 변화의 금리 직교 잔차]
                + β4·r_EWY_adj                   [EWY 원화환산 − KOSPI 내재 괴리]
                + β5·Δy2                         [미국채 2Y 당일 변화, bp]  ← 신규
                + β6·(Δy10 − Δy2)                [커브 성분 분리]           ← 신규
                + β7·CLV_us                      [미 세션 질: SOXX 종가의 레인지 내 위치] ← 신규
                + β8·r_us_last30m                [미 마지막 30분 모멘텀]     ← 신규
                + β9·breadth_us                  [미 시장 폭 (상승종목비율)]  ← 신규
```

**이중계상 방지 (사슬 직교화)**: 금리→달러→환율은 같은 전달 사슬이다 (G1A와 동일 원칙).
Δfx는 원변수가 아니라 **Δy2에 회귀한 잔차(Δfx_orth)** 로 투입한다 — 금리로 설명되는
환율 변동은 β5가 이미 담으므로, 환율 변수에는 금리 무관 성분(수급·개입·국내 요인)만 남긴다.
r_peer도 동일하게 SOXX 직교 잔차만 사용 (v0.1 승계).

**채택 판정은 모델 사다리로**: β5~β9는 후보이지 확정이 아니다. G1B-R에서 M0(SOXX 단독)부터
한 변수씩 추가하며 **아웃오브샘플 translation_error가 개선되는 변수만 채택**한다.
개선 없는 변수를 "이론적으로 맞으니까" 남기지 않는다 (과최적화 방지).

세션 질 변수(β7·β8)의 근거: 같은 SOXX −2%라도 저가 마감(밀린 밤)과 낙폭 축소 마감(반등한 밤)은
다음날 아시아의 소화 방향이 다르다. 이 변수들은 FairGap보다 **R2 잔차 트레이드(과소/과잉반응 판정)**
에서 효과가 클 것으로 예상 — 사전 등록해두고 실측으로 확인.

### 3.2 Layer 2 — 실시간 관측 (시점별 갱신)

**R1 시점 (07:15 절단):**
```
Obs_R1 = v1·NightFut + v2·GDR + v3·AH + v4·GX1          (Σv = 1, 초기 0.4/0.2/0.25/0.15)

NightFut : KRX 야간선물 내재 지수갭 (거래 불가, 관측 전용)
GDR      : 삼전 GDR(LSE)·하닉 GDR 원화 환산 괴리 (하닉은 괴리 2% 이내만 신뢰)
AH       : β_ah × r_시간외바스켓 — 미 반도체 시간외(정규 종가→07:15) 수익률의 전이
           ※ 실적 발표 밤엔 이 항이 Layer 2의 지배 항이 된다
GX1      : β_gx × Δ미선물(정규 마감→07:15) — 글로벡스 마감 후 변화분
```

**R2 시점 (08:45 절단) — 아시아의 밤 소화 실측:**
```
ΔAsia   = γ1·(r_ASX 개장~08:45) + γ2·(r_니케이선물 조기세션)     (초기 γ1=γ2=0.1)
ΔGlobex2 = γ3·Δ미선물(07:15→08:45)                              (초기 γ3=0.3)
```
- ASX(08:00 KST 개장)와 니케이 선물 조기 세션은 밤사이 정보를 아시아 시장이 어떻게
  소화하는지의 **첫 실측치**다. 미국 데이터의 재탕이 아니라, "아시아가 미국을 어떻게
  번역하는가"라는 신규 정보이므로 이중계상이 아니다 — 단 γ는 작게 시작한다
  (이미 FairGap_R1에 담긴 방향과 상관이 높으므로 증분 정보만 반영).
- NXT 프리마켓(08:00~) 삼전/하닉 자체 가격은 **FairGap 입력이 아니라 검증 대상**이다
  — 예상과 실거래가의 괴리는 §6 잔차 판정으로 처리 (자기 자신을 예측 변수로 쓰지 않는다).

### 3.3 Layer 3 — 정성 오버레이

```
δ_event  : 이벤트 전용 조정 (§5에서 정의 — 규칙 기반)
δ_manual : 수동 정성 조정, 상한 ±0.5%, 사유 기록 강제
```

δ_manual의 규율 (재량의 제도화):
1. 입력 시 **Q1 cause 태그 + 한 줄 사유** 없이는 시스템이 접수 거부.
2. 대상: 어떤 가격에도 반영이 불충분하다고 판단되는 정보만 — 한국 고유 뉴스(공시·규제·지정학의
   한국 비대칭 노출), 가이던스 뉘앙스, 재평가 vs 청산 랠리 판단.
3. **사후 심판**: 60일 로그에서 "δ_manual 사용일 vs 미사용일"의 translation_error를 분리 집계.
   δ가 오차를 줄이지 못하면 상한을 ±0.25%로 축소, 개선하면 유지. 정성 판단도
   luck 분류 원칙과 같은 방식으로 데이터의 심판을 받는다.

### 3.4 레짐별 동적 가중 w_reg

| 레짐 | w_reg | 논리 |
|---|---|---|
| 평상 밤 | 0.5 | 회귀·관측 균형 |
| **바이너리 이벤트 밤** | **0.2** | 평상시 β 신뢰 불가 → 시장이 매기는 가격(Layer 2) 우선 |
| 대변동 밤 (미 지수 ±3% 이상) | 0.2 | 동일 |
| Layer 2 소스 결측·상호 1% 초과 불일치 | 0.8 | 관측 신뢰 불가 → 회귀로 후퇴 + 잔차 트레이드 금지 |

## 4. 자기 자신을 예측하지 않기 — 변수 편입 심사 기준

모든 신규 변수는 편입 전에 다음 질문을 통과해야 한다 (스펙 개정 시에도 적용):

1. 이 변수의 정보는 이미 Layer 1/2의 다른 변수 가격에 반영돼 있는가? → 반영분은 직교화로 제거
2. 이 변수는 예측 대상(삼전/하닉 개장가) 자신의 사전 거래가인가? → 입력 금지, 잔차 검증용으로만
3. 이 변수는 R1/R2 절단 시각에 실제로 관측 가능한가? → 타임스탬프 감사 필수

## 5. 이벤트의 처리 — "가격에 이미 반영되지 않았나"에 대한 답

이벤트 결과의 방향·크기의 1차 정보는 **맞다, 이미 SOXX·시간외·선물 가격에 반영돼 있다.**
따라서 이벤트 변수를 가격 변수와 병렬로 가산하면 이중계상이다. 이벤트는 가산항이 아니라
다음 세 가지 **비가격 역할**로만 모델에 들어간다:

**역할 ① — 레짐 스위치 (관계의 신뢰도 조절)**
이벤트 밤은 β가 추정된 평상시 관계가 무너지는 밤이다. 이벤트 플래그는 FairGap 값을 바꾸는 게
아니라 **w_reg를 0.2로 낮춰 회귀 의존을 줄인다** (§3.4). 정보는 가격(Layer 2)이 담게 하고,
모델은 자기 신뢰도를 낮추는 것.

**역할 ② — 서프라이즈 상호작용 (잔차·드리프트 예측)**
```
SurpriseZ = (실제치 − 컨센서스) ÷ 해당 지표 서프라이즈의 과거 표준편차
UnderReact 플래그 = |SurpriseZ| ≥ 1.5  AND  |가격 반응| < 0.7 × implied move
```
가격이 서프라이즈 크기만큼 못 움직인 밤은 과소반응 → 다음날 시가 이후 동방향 드리프트 확률 상승.
이 플래그는 FairGap이 아니라 **R2 잔차 판정의 방향 결정(§6)과 페이드 금지 규칙**에 들어간다.
즉 이벤트 정량 데이터(컨센서스 괴리)는 "시가 예측"이 아니라 "시가 이후 궤적 예측"에 쓴다 —
가격에 반영 안 된 것은 이벤트의 발생이 아니라 **시장 반응의 과부족**이기 때문이다.

**역할 ③ — 국내 고유 전달 (δ_event)**
미국 가격에 구조적으로 덜 반영되는 이벤트 — 대중 수출규제, 반도체 관세, 한국 비대칭 지정학 —
는 SOXX가 담지 못한다. 이 경우에만 δ_event로 직접 가산하되, 크기는 과거 유사 케이스(Q1)의
반응 분포에서 취하고 상한 ±1.0%. Q1 케이스 매칭이 이 항의 공식 산출 경로다.

## 6. R1 조정 매트릭스와 R2 잔차 판정

### 6.1 R1 — G1A 대조 (정합 규칙)

기준: **잔여기대 = ExpectedOpen_R1 ÷ G1A 진입가 − 1**

| G1A 예측 | 잔여기대 | 판정 | 조치 |
|---|---|---|---|
| UP 보유 | ≥ +0.5% | 적중·잔여 有 | 유지, 추격 금지, 시가+30분 익절 계획 |
| UP 보유 | +0.1~+0.5% | 적중·소폭 | 유지, 시가 익절 |
| UP 보유 | −0.3~+0.1% | 무승부 | 프리장 절반 축소, 시가 정리 |
| UP 보유 | ≤ −0.3% | **오판 확정** | 08:00 NXT 즉시 청산, 물타기 금지. 반전 신진입은 G1B 단독 신호로만, 1/6 상한 |
| NEUTRAL | \|FairGap_R1\| ≥ 0.8% | 잔여분 기회 | 프리장 유동성 확인 후 1/6 한정 (로그 기간엔 기록만) |
| DOWN 보유 | (대칭) | — | — |

원칙: **G1A의 손익은 R1 시점에 이미 결정돼 있다.** R1의 역할은 그 결과를 인정하고
잔여분/잔차라는 다음 트레이드로 넘어가는 것이다. 전일 판정 방어를 위한 홀딩 금지.

### 6.2 R2 — 잔차 판정 (갱신된 이론가 기준)

```
Residual = 동시호가 예상체결가(08:40~08:45 평균) − ExpectedOpen_R2
```

| 조건 | 해석 | 신호 |
|---|---|---|
| \|Residual\| < 0.3% | 정상 번역 | 무신호 |
| Residual ≤ −0.4% | 과소반영 시가 | 시가 매수 → ExpectedOpen_R2 수렴 목표, 시한 09:30 |
| Residual ≥ +0.4% | 과잉반영 시가 | 갭 페이드 후보 — 단 아래 금지 조건 선행 |
