## 1. 목적

미장 마감 후 ~ 국장 개장 전에 축적되는 가용 정량·정성 정보를 종합하여:

1. **FairGap(공정 갭)과 그 불확실성(σ_night)** 을 산출·갱신하고 (R1 07:20 → R2 08:55),
2. G1A 포지션의 조정 지시(추가/유지/후퇴/반전)를 내리며,
3. 실제 시가의 잔차를 σ 기준으로 판정해 시가 부근 트레이드 신호를 낸다.

제1 원칙 (v0.2 승계): **가격에 이미 반영된 정보와 미반영 정보를 구분한다.** 모든 변수는
"어떤 가격에도 아직 반영되지 않은 성분인가"를 통과해야 편입된다.
제2 원칙 (v0.3 신설): **점 추정을 믿지 않는다.** FairGap은 항상 구간(±σ)으로 산출·보고되며,
행동 임계값은 그 밤의 σ에 연동된다.

## 3. FairGap 산출 — 지수/고유 이단 분해 (v0.3 핵심 구조)

### 3.0 왜 분해하는가

야간선물·ASX·글로벡스는 **지수(시장 전체)** 를 말하고, GDR·시간외 반도체·TSM은 **종목/섹터**를
말한다. 이를 한 줄로 평균하면 "MU 실적 쇼크로 하닉만 움직일 밤"에 조용한 지수 신호가
종목 신호를 희석하는 오류가 생긴다. 따라서:

```
FairGap_종목 = β_mkt · G_idx  +  G_idio  +  δ_event + δ_manual + AdjEx

G_idx  : 시장(KOSPI200) 예상 갭 — 지수 채널
G_idio : 해당 종목의 시장 초과 고유 갭 — 종목 채널
β_mkt  : 종목의 대시장 베타 (롤링 120일, 하닉 > 삼전)
AdjEx  : 배당락·권리락 기계 조정 (§3.4)
```

### 3.1 지수 채널 G_idx

```
G_idx = w_reg(레짐) · G_idx_reg + (1 − w_reg) · G_idx_obs

[회귀부] G_idx_reg = α + b1·r_SPX + b2·Δy2 + b3·(Δy10−Δy2) + b4·Δfx_orth
                       + b5·CLV_us + b6·r_us_last30m + b7·breadth_us
[관측부] G_idx_obs = u1·야간선물내재갭 + u2·(β_gx·Δ글로벡스) + u3·(β_tw·TAIFEX야간)
                     (Σu=1, 초기 0.5/0.3/0.2)
```

- 지수 회귀의 미국 대표는 SPX (반도체 성분은 고유 채널이 담당 — 채널 간 이중계상 방지).
- TAIFEX 야간선물(새벽 5시 마감)은 "아시아 시장에 대한 밤사이 가격표"로 야간선물의 교차 검증.
- 세션 질 3종(b5~b7)은 지수 채널 소속. R2 잔차 판정에서 재사용.

### 3.2 고유 채널 G_idio

```
G_idio = w_reg(레짐) · G_idio_reg + (1 − w_reg) · G_idio_obs

[회귀부] G_idio_reg = α' + c1·(r_SOXX − β_soxx,spx·r_SPX)     [SOXX의 대시장 초과분]
                          + c2·r_peer_orth                      [MU/NVDA의 SOXX 직교 잔차]
                          + c3·(r_TSM − β_tsm,soxx·r_SOXX)     [TSM의 대SOXX 초과분] ← 신규
[관측부] G_idio_obs = v1·GDR괴리 + v2·(β_ah·r_시간외바스켓_초과)
                      (Σv=1, 초기 0.45/0.55 — 실적 밤엔 v2 지배가 정상)
```

- 모든 회귀 변수가 **상위 채널에 직교화**되어 들어간다: SOXX는 SPX 초과분만, TSM은 SOXX 초과분만,
  peer는 SOXX 잔차만. 채널 안팎 어디서도 같은 정보를 두 번 세지 않는 것이 이 구조의 목적이다.
- 시간외 바스켓도 시간외 SPY 대비 초과분으로 계산 (지수 채널과의 분리 유지).
- TSM ADR: 아시아 반도체에 대한 미국 시장의 직접 가격표. "미 매크로 조용 + 아시아 서플라이체인
  뉴스" 밤에 SOXX보다 정확할 것으로 예상 (사전 등록, G1B-R에서 검증).

### 3.3 레짐별 동적 가중 w_reg (v0.2 승계, 채널별 적용)

| 레짐 | w_reg | 비고 |
|---|---|---|
| 평상 밤 | 0.5 | |
| 바이너리 이벤트·대변동 밤 (미 지수 ±3%) | 0.2 | 시장 가격 우선, 모델 자기신뢰 하향 |
| 관측부 결측·상호 1% 초과 불일치 | 0.8 | 회귀 후퇴 + 잔차 트레이드 금지 |

- 이벤트의 3역할(레짐 스위치 / SurpriseZ·UnderReact 상호작용 / δ_event 국내 고유 전달)은
  v0.2 §5 그대로 승계. 고유 채널 이벤트(실적)는 G_idio의 w_reg만, 매크로 이벤트는 양 채널 모두 전환.

### 3.4 기계 조정항 AdjEx (신설 — 필수 처리)

```
AdjEx = −(배당금 ÷ 전일 종가)   [배당락일] ,  권리락은 이론락가 공식 적용
```
- 락일 캘린더를 사전 수집. 미조정 시 해당일 translation_error가 오염되고 "하방 갭 오판"으로
  잘못 기록되므로, 라벨 계산과 FairGap 양쪽에 동일 적용한다. 락일은 로그에 `ex_date=true` 플래그.

### 3.5 R2 갱신 (v0.2 승계)

```
FairGap_R2 = FairGap_R1 + γ1·r_ASX(08:00~08:45) + γ2·r_니케이선물조기 + γ3·Δ글로벡스(07:15→08:45)
```
γ 초기값 0.1/0.1/0.3. 아시아 신호는 지수 채널 갱신으로 귀속. NXT 프리마켓 자체 가격은
입력 금지 — 잔차 검증 대상 (자기 자신 예측 금지, v0.2 §4 승계).

## 4. 불확실성 정량화 σ_night (v0.3 핵심 신설)

### 4.1 산출

```
σ_night = σ_base(레짐) × k_event

σ_base : 최근 120일 번역 잔차의 레짐별 조건부 표준편차
         (평상 밤 / 이벤트 밤 / 대변동 밤 별도 추정 — G1B-R 산출물)
k_event: 당일 implied move ÷ 평상시 implied move (이벤트 밤만, 상한 2.0)
```

### 4.2 전 임계값의 σ 전환

| 판정 | v0.2 (고정 %) | v0.3 (σ 기준) |
|---|---|---|
| R1 잔여기대 "적중·잔여 有" | ≥ +0.5% | ≥ +0.8σ |
| R1 "오판 확정" | ≤ −0.3% | ≤ −0.5σ |
| R2 잔차 무신호 밴드 | < 0.3% | < 0.7σ |
| R2 잔차 신호 발동 | ≥ 0.4% | **≥ 1.2σ** |
| Layer 2 상호 불일치 판정 | > 1.0% | > 1.5σ |

- 논리: 조용한 밤의 0.4% 잔차는 신호지만 미 지수 ±2% 밤의 0.4%는 노이즈다. 고정 %는
  이 차이를 못 본다. σ 연동으로 "그 밤의 정상 오차 대비 몇 배인가"를 판정 기준으로 삼는다.
- 리포트는 항상 구간 표기: `예상시가 197,900 ± 800 (1σ)`.
- 사이징 연동: |신호| ≥ 1.2σ → 1/6, ≥ 2.0σ → 1/3 검토 (단 §7 abstain 우선).

기준: 잔여기대 = ExpectedOpen_R1 ÷ G1A 진입가 − 1, 단위는 그 밤의 σ.

| G1A 예측 | 잔여기대 | 판정 | 조치 |
|---|---|---|---|
| UP 보유 | ≥ +0.8σ | 적중·잔여 有 | 유지, 추격 금지, 시가+30분 익절 계획 |
| UP 보유 | +0.2σ ~ +0.8σ | 적중·소폭 | 유지, 시가 익절 |
| UP 보유 | −0.5σ ~ +0.2σ | 무승부 | 프리장 절반 축소, 시가 정리 |
| UP 보유 | ≤ −0.5σ | **오판 확정** | 08:00 NXT 즉시 청산, 물타기 금지. 반전 신진입 1/6 상한 |
| NEUTRAL | \|FairGap_R1\| ≥ 1.2σ | 잔여분 기회 | 1/6 한정 (로그 기간엔 기록만) |
| DOWN 보유 | (대칭) | — | — |

```
Residual = 동시호가 예상체결가(08:40~08:45 평균) − ExpectedOpen_R2
```

| 조건 | 해석 | 신호 |

## 7. 판정 보류 (abstain)

1. 미장 휴장/반일장 → G1B 보류, G1A 포지션 시가 정리 기본값.
2. w_reg=0.8 레짐 → 잔차 트레이드 금지, 조정 지시만.
3. 개장 전 국내 단독 대형 공시 → FairGap 무효 선언, 수동 모드 전환.
4. δ_manual이 정량 층과 충돌하며 상한 도달 → 사이징 전면 1/6 강등.
5. **건강 경보 발동 중 (§9)** → 잔차 트레이드 금지, R1 조정 지시는 유지하되 σ 1.5배 확대 적용.
6. 배당락일 → 잔차 트레이드 보류 (AdjEx 정밀도 검증 전까지, 60일 로그 후 재평가).

## 8. Layer 3 정성 오버레이 (v0.2 승계 요약)

δ_event: 국내 고유 전달만, Q1 케이스 분포 기반, 상한 ±1.0%.
δ_manual: 상한 ±0.5%, Q1 태그+사유 강제, 사용일/미사용일 오차 분리 집계로 사후 심판
(개선 실패 시 상한 ±0.25% 축소). 락일·수동 모드에서는 δ 체계 전체 무효.

## 9. 모델 건강 감시 (신설)

모델이 자기 성적표를 실시간으로 본다. 관계 붕괴(예: HBM 내러티브로 하닉의 SOX 디커플링)를
주 1회 재추정보다 빨리 잡기 위한 장치.

```
건강지표 H = translation_error_r2의 5일 이동 MAE
경보 발동: H > 직전 60일 H 분포의 90분위
```

| 상태 | 자동 조치 |
|---|---|
| 정상 | — |
| **경보 (레짐 의심)** | w_reg 1단계 강등(0.5→0.2) + σ_night 1.5배 확대 + 잔차 트레이드 금지 + 리포트에 "레짐 의심" 표기 |
| 경보 10일 지속 | β 재추정 윈도 120→60일 단축 + 수동 리뷰 소집 (채널별 오차 분해로 붕괴 지점 특정) |
| 해제 | H가 중앙값 복귀 후 3일 유지 |

- 채널별 오차 분해(지수 채널 오차 vs 고유 채널 오차)를 상시 기록 — 경보 시 어느 채널이
  깨졌는지 즉시 식별 가능하게 (§3의 분해 구조가 여기서 진단 도구가 된다).
