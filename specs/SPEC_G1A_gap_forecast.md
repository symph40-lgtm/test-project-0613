## 1. 목적과 역할 분담

G1A는 저녁 시간대(16:30~19:40 KST)에 **유럽장 개장 반응과 미국 프리마켓 초반 추세가 확인되는 즉시**
D+1 시가 갭의 잔여분을 판정하고, NXT 애프터마켓 진입 지시 리포트를 발행한다.

- 포획 대상은 갭 전체가 아니라 **진입 시점 이후의 잔여분**이다. 조기에 확인될수록 잔여분이 크고,
  늦게 확인될수록 확실성이 크다 — 이 트레이드오프를 시간 가변 임계값(§5.3)으로 명시적으로 관리한다.
- 판정 이후는 G1B가 승계한다: 07:20 R1(조정 지시), 08:55 R2(잔차 판정).
- T1(15:10)은 자본이 걸리지 않는 스냅샷이다 (§7). 미래의 T1 재활성화 판단을 위한
  진짜 아웃오브샘플 데이터 축적 + T2 리포트의 "저녁 사이 변화" 기준점 역할만 한다.

## 2. 일일 사이클

```
15:10  T1 스냅샷 자동 기록 (판정 없음)
16:30  T2 감시 루프 개시 (10분 주기 평가)         ← 유럽 개장 +30분 이후
17~18시 미 프리마켓 개장 (서머타임 17:00 / 표준시 18:00 KST)
  ↓    조기 트리거 조건 충족 시 → 즉시 T2-E 리포트 + NXT 진입
  ↓    미충족 지속 시 → 19:40 T2-F 최종 판정 (진입 또는 NEUTRAL 확정)
  ↓    진입 후에는 반전 감시 (19:55까지, §5.5)
20:00  NXT 애프터마켓 마감 — 이후 포지션 변경 불가
07:20  G1B R1 (조정 지시)
08:55  G1B R2 (잔차 판정)

09:30  청산 기본값 (L3 구간 종료)
```

## 3. 라벨 정의

| 라벨 | 정의 | 용도 |
|---|---|---|
| **L1' (주)** | T2 진입가(NXT 체결가, log-only 기간엔 트리거 시점 중간호가) → D+1 KRX 시가 | G1A 평가 기준 |
| L1 (참고) | D일 KRX 종가 → D+1 시가 | 갭 전체 대비 포획률 계산용 |
| L2 (보조) | 진입가 → D+1 NXT 프리마켓 첫 체결가 | 프리장 조기청산 검증 |
| L3 (보조) | D+1 시가 → 시가+30분 | G1B 잔차 검증 |

- 방향 분류: L1' 기준 UP(≥+0.3%) / DOWN(≤−0.3%) / FLAT.
- **포획률 = L1' ÷ L1** 을 매일 기록 — 조기 트리거가 실제로 잔여분을 더 먹는지의 직접 증거.

## 4. 입력 피처 (T2)

### 4.1 잔여갭 추정의 중심 식

```
예상잔여갭 = β_pm · r_basket − r_NXT

r_basket : 미 프리마켓 반도체 바스켓 수익률
           (하닉: MU 0.5·NVDA 0.3·SOXL/3 0.2 / 삼전: NVDA·MU·AMD 균등 — 초기값)
β_pm     : 프리마켓→시가 전이 베타 (G1B-R에서 정규장 β와 별도 추정, 초기값 = 정규장 β 준용)
r_NXT    : 당일 NXT 애프터마켓에서 이미 반영된 삼전/하닉 수익률 (16:00 기준 → 실시간)
```

r_NXT를 **차감항**으로 쓰는 것이 v0.3의 핵심이다: NXT가 이미 프리마켓을 반영해 떠 있으면
그만큼은 먹을 수 없는 몫이므로 가산 피처가 아니라 공제 항목이다 (v0.1의 F23 역할 재지정).

## 5. 판정 로직

### 5.1 조기 트리거 (T2-E) — 전 조건 동시 충족 시 즉시 발동

1. **관측 충분성**: 미 프리마켓 관측 경과 ≥ 30분 AND 유럽 개장 경과 ≥ 30분
2. **방향 지속성**: DC-PM ≥ 60% (프리마켓이 방향을 "유지"하고 있는가)
3. **크기 유의성**: |r_basket| ≥ 0.5% (노이즈 배제)
4. **3자 일치**: 유럽 톤 · 미 선물 · 프리마켓 바스켓의 부호 일치 (충돌 시 대기)
5. **점수 통과**: |GapScore| ≥ θ(t) — 시간 가변 임계값 (§5.3)
6. **경제성**: 예상잔여갭 − 왕복비용(NXT 스프레드 + 수수료·세금 + 슬리피지 버퍼) ≥ **+0.3%**
7. **유동성 게이트 통과** (§5.4)

### 5.2 최종 판정 (T2-F, 19:40)

조기 트리거 미발동 시 19:40에 동일 조건으로 1회 최종 평가. 조건 미달이면 **NEUTRAL 확정** — 그날 밤은 쉰다.

### 5.3 시간 가변 임계값 θ(t) — 트레이드오프의 명시적 가격표

일찍 진입할수록 잔여분은 크지만 정보는 적다. 따라서 이른 시각일수록 더 강한 증거를 요구한다.

| 트리거 시각 | θ_High | θ_Low | 논리 |
|---|---|---|---|
| ~18:30 | 6.0 | 3.0 | 프리마켓 초반 — 최대 증거 요구 |
| 18:30~19:20 | 5.5 | 2.75 | |
| 19:20~19:40 (T2-F 포함) | 5.0 | 2.5 | 정보 최대 — 기본 임계값 |

사이징: High → 1/3, Low → 1/6 (DC-PM 확인은 High의 전제조건). **삼전+하닉 동시 신호 시 합산 익스포저 상한 = 1/3** (상관 0.7~0.8이므로 사실상 단일 베팅으로 취급).

### 5.4 NXT 유동성 게이트

| 진입 시점 스프레드 | 조치 |
|---|---|
| ≤ 0.10% | 정상 |
| 0.10~0.20% | 사이징 1단계 강등 |
| > 0.20% | **진입 보류** — 스프레드 축소 대기, 19:55까지 미개선 시 NEUTRAL |

- log-only 60일간 매일 16:30~19:55 스프레드·최우선잔량을 10분 주기 기록 → 임계값 실측 재조정.
- 진입 주문은 지정가만. 시장가 금지 (얇은 호가에서 슬리피지 통제 불능).

### 5.5 진입 후 반전 감시 (트리거 ~ 19:55)

조기 진입의 대가는 진입 후 프리마켓이 뒤집힐 수 있다는 것. 20:00 이후엔 손 쓸 수 없으므로 마지막 감시 창을 둔다.

- GapScore 부호 반전 또는 DC-PM < 40% 붕괴 → **19:55까지 NXT에서 전량 청산** (수정 리포트 발행)
- High→Low 강등 수준 약화 → 절반 축소
- 20:00 이후의 반전은 G1B R1(07:20)이 처리 — 이것이 G1B가 존재하는 이유다

### 5.6 판정 보류 (abstain) — 점수보다 우선

1. **바이너리 이벤트 밤** (FOMC·CPI·고용·대형 실적). T2가 프리마켓을 봤더라도 이벤트는 T2 이후(CPI 21:30, FOMC 새벽)에 나온다 — 프리마켓은 이벤트 결과를 모르는 가격이다. implied move ≥ 1.5×평상시도 동일.
2. **금요일** (주말 보유 금지) + 한국 연휴 전일.
3. **미국 휴장·반일장 밤** — 갭 동력 자체가 없음.
4. **선물옵션 동시만기일 D+1, MSCI·대형 패시브 리밸런싱일 D+1** — 수급 왜곡 갭.
5. 서킷브레이커 발동일 당일·익일.
6. 포지셔닝 극단(F17) + 점수가 뉴스 방향과 동일 → 사이징 강등 (sell-the-news).
7. 핵심 피처 결측 2개 이상, 개별 공시(자사주·유증 등) 발생 시.

## 11. 검증 계획 (log-only 60일)

> **[개정 고지]** 일정 체계는 SPEC_G1_OPT_loop.md가 지배한다: D+15 1차 사용가능 판정 →
> D+30 소액 활성화 → D+60 본 판정 → 상시 최적화 루프. 아래 평가지표·합격 기준·판정
> 비대칭 원칙은 D+60 본 판정 기준으로 유효.

- 평가지표: L1' 적중률·expectancy, **포획률 분포(트리거 시각별)**, Brier, 반전 감시 발동률과 그 손익 기여,
  abstain일의 실제 갭 분포, 스프레드 실측 분포.
- **베이스라인 3종 필수 대조**: ① 무거래 ② "당일 KOSPI 방향=익일 갭" 관성 ③ 미 프리마켓 바스켓 부호 단독(19:40 고정 진입).
  특히 ③을 못 이기면 피처 체계 전체가 프리마켓 1개 변수보다 못한 것 — 이 경우 시스템을 단순화한다.
- **판정 비대칭 원칙**: 백테스트·로그의 양성 결과는 할인해서 수용(합격은 입장권), 음성 결과는 신뢰(기각은 확정).
  좋은 숫자가 나와도 60일을 건너뛰지 않는다.
- 합격 기준(초안): High 적중률 ≥ 60% (T2는 번역 성격이 섞이므로 v0.1의 58%보다 상향) 또는
  expectancy > 왕복비용 2배, AND 베이스라인 ③ 초과.
