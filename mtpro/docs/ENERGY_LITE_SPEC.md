## 1. Energy-Lite란 무엇인가

MT-PRO의 최종 목표는 삼성전자·SK하이닉스의 **반응함수 상태 엔진**이다.
정식 버전의 핵심 재료 두 가지 — ①발표 전 컨센서스, ②장중 분봉 — 는
과거로 소급 조달이 불가능하다는 것이 T1 실측 결과였다:

- 컨센서스: 자동 소스 부재, 과거 값 복원은 사후 수정 오염 위험 → 소급 불가
- 분봉: KIS 보유 약 12개월 (3년 소급 불가)

**Energy-Lite = 3년 소급이 가능한 일봉 재료만으로 만든 간이 대역(proxy).**
"약할 것"은 설계 시점부터 예고된 한계였다 (T1 기록: "등급C 약함은 예고된 한계").
목적은 정식 버전 개발 전에 "일봉 프록시만으로도 신호가 성립하는가"를
가설로 세우고 관문으로 판정하는 것이었다.

## 2. 사양 (확정 구현 기준)

### 2.1 구성 — 3 컴포넌트 (전부 일봉, 2023-01~ 소급)

```
Energy-Lite = 균등가중 평균 (가중치 사전 등록)

① FlowImpactResidual_z   [부품 4]
   외국인·기관 순매수(pykrx, KOSPI_MARKET 단위) 대비
   가격 반응의 잔차를 표준화.
   "같은 수급 충격에 가격이 예상보다 덜/더 움직였는가"

② BreadthImpulse_z       [부품 5]
   KOSPI200 PIT 구성종목의 20일선 위 비율,
   최근 5거래일 vs 이전 15거래일 변화율의 z.
   "시장 참여 폭이 넓어지고 있는가"

③ gradec_err             [부품 0~2 등급C 모드]
   방향만 아는 이벤트(전일밤 SOX 프록시)의
   open→close 표준화 수익률 (갭 제외, 당시 A-1 기준).
   ※ 퇴화 기록: β_SOX ≈ 0 실측 → β 하한 0.3에 100% 도달
      → 사실상 "이벤트일 표준화 수익률"로 상수 모델화 (D-A 결정에 명기)
```

### 2.2 결측·결합 규칙

- min_components = 2 (미달 시 Energy-Lite = None) — Lite 전용 예외,
  완전판은 3 (부록 A-6 각주 등재)
- None 컴포넌트는 제외 후 잔여 가중 재정규화 ("가용한 것의 평균")
- 결측 0 대체 금지 — "모름"과 "중립"은 다르다
- 미국 휴장일 SOX 재사용 금지 → None (D-E: 재사용된 값은 새 정보가 아니다)

| 결정 | 내용 |

| amendment 재측정 | **기각** — 조건을 고쳐 같은 표본을 다시 재는 것은 소진 표본 재사용 |

| **현재 지위** | **미채택 · log-only 지속** — 라이브 가동 시 매일 계산·기록만, 어떤 판단에도 미사용 |

### 재검증에 관한 규율 (문의 대비 기록)

AM-9(반응함수 기준)로 소진 표본을 재측정하지 않는 이유:
1. 결과를 본 뒤 잣대를 바꿔 같은 데이터에 두 번째 기회를 주는 것 —
   사전 등록 체계의 근간 훼손 (NM3 DSR 교훈과 동일 사안)
2. 성공해도 결정 가치 없음 — 완전판이 Lite의 재료를 포함·상회하므로
   Lite를 채택할 시나리오가 존재하지 않는다
3. 정당한 경로가 이미 열려 있음 (아래)

### 열려 있는 정당한 경로 2개

- **라이브 신규 표본 재관문:** log-only로 쌓이는 라이브 데이터는 신규 표본.
  사전 등록 신규 게이트로 Lite를 재관문하는 것은 합법이며,
  완전판의 대조군 역할로 가치 있음.
- **T5.5 (12개월 분봉 소급):** 측정 대상(부품 3·3G)과 데이터(분봉)가
  소진 표본과 별개. AM-9 질문의 첫 답은 여기서 — Lite가 아니라 정식 부품으로.

## 5. Energy-Lite가 남긴 것 (완전판 설계에의 기여)

FAIL했으나 다음을 프로젝트에 남겼다:

1. **인프라 검증 완료:** bronze/silver/gold 계층·PIT 구성종목·수급 적재·
   lookahead 절단 테스트 — 전부 완전판이 그대로 상속
2. **β_SOX ≈ 0 실측:** "개장 전 재료의 정보는 갭에 있다" → A-1R 개정
   (갭을 실현 반응으로 복원)의 보조 진단 근거
3. **C-1 대사 확정:** KOSPI_MARKET 수급 단위 — 완전판 부품 4가 상속
4. **관문 규율의 실증:** 사전 등록 → FAIL 그대로 보고 → 소진 선언의
   전 과정이 실제로 작동함을 증명. "자기가 만든 것을 자기가 나쁘다고
   보고하는 시스템"의 첫 사례
5. **검증 철학의 반성:** 수익률 IC 중심 관문이 MT의 주장과 어긋난
   잣대였다는 인식 → AM-9 (반응함수 재현성) 탄생의 계기
