## 2. 부품 구성 (데이터 현실 기준, 부품 8 제외한 0~7)

### 2.1 이중 트랙 구조

```
[소급 트랙] 2023-01 ~ 현재 (일봉 + 수급 + breadth)
├─ 부품 4: Flow Impact          ← pykrx 3년 (T1-1 확정 후)

├─ 부품 0~2 (등급C 모드): 방향만 아는 이벤트 + 일봉 반응
│   └─ Expected Reaction: 일봉 기준 / ERR: 일봉 종가 기준, Implicit only
└─ 부품 6~7 (부분): Energy-Lite = f(flow, breadth, 등급C ERR)
    └─ 가중치 사전 등록 후 측정

[전진 트랙] 라이브 시작일 ~ (분봉 + 수동 컨센서스)
├─ 부품 0~2 (등급A 모드): 수동 컨센서스 + SurpriseZ + 장중 반응
├─ 부품 3: Shock Absorption      ← 분봉 필요, 라이브만
└─ 부품 6~7 (완전판): Energy + Regime + Transition + Confidence
```

### 2.2 Amendment A-1 — 개장 전 재료의 시간축

국내 자산에 대해 KRX 휴장 중 발표된 재료(FOMC·CPI·개장 전 잠정실적)는:

- t0 = **당일(익일) 09:00 시가**
- 갭(전일 종가 → 시가)은 **MT 입력에서 제외** — MT-PRO는 갭이 아니라 **갭 이후의 장중 소화 과정**을 측정한다는 것이 이 시스템의 측정 대상 정의
- 타임포인트: t1=09:05, t2=peak adverse(시가 대비), t3=09:30, t4=14:30, t5=종가. t6(익일 갭) **삭제**
- SOXX 등 미국 자산 이벤트는 원 사양(발표 시각 t0) 유지

**기록 의무:** 사양 이탈은 amendment로 기록. 조용한 수정 금지.

## 부록 A — DEV_COMPLETE_SPEC.md 결함 정오표 (구현 전 필독)

각각 **검출 테스트 먼저 → 수정 구현** 순서.

| # | 결함 | 수정 방향 | 검출 테스트 |
|---|------|----------|------------|
| A-1 | `expected_std` 사실상 상수(≈0.5) → ERR~N(0,1) 검증 무의미 | expected_std = 회귀 잔차의 rolling std (event_type별), 하한 floor만 상수 | std(ERR_z) ∈ [0.7, 1.3] 검증이 실제로 실패 가능해야 함 |
| A-2 | regime 조건 전부 불충족 시 확률합 0 → 0.01 나눗셈 왜곡 | fallback: 직전 regime 유지 + confidence 감점, 직전 없으면 uniform 명시 | 전 조건 미충족 입력에서 확률합 == 1.0, NaN 없음 |
| A-3 | sticky 가점 매일 누적 → 탈출 불가 | 가점이 아닌 **전환 임계 방식**: 신규 regime 확률이 현 regime + 마진(0.15)을 2일 연속 초과 시만 전환 | 강신호 시계열에서 전환이 실제 발생하는지 |
| A-4 | good/bad 표본 <2일 때 asymmetry=0.0 → "중립"과 "모름" 구분 불가 (quiet reset 계열) | 표본 부족 시 None + "insufficient" 플래그, Energy 가중에서 제외 후 재정규화 | 표본 0 입력에서 0.0 아닌 None 반환 |
| A-5 | attribution_quality 겹침 감지 로직 코드 미구현 | 동일 t0 윈도 내 복수 이벤트 → 감점 공식 코드 확정, 사전 등록 | 동시각 2개 이벤트에서 quality < 1.0 |
| A-6 | Energy 컴포넌트 None 처리 없음 → NaN 전파 | A-4 연동: None 제외 + 가중치 재정규화 + 컴포넌트 <3이면 Energy도 None | 2개 None 입력에서 Energy 값 + available_components 필드 검증 |
