## 성분 (등록 시점 고정) — 발주자 지적 반영: 단창 노이즈·갭·이벤트 자동화
- **ⓐ' 바스켓 다창 기울기**: 30분 / 60분 / 프리마켓 세션 3창 변화율 — 문턱 0.15 / 0.25 / 0.3% — **3창 중 2창 동방향**일 때 1표.
  **2차 가속**(최근 30분 − 직전 30분)이 표 방향과 반대로 ≥0.15%면 표 철회(감속 중 오판 차단).
  **갭 반표**: 프리마켓 시작가 vs 전일 최종가(프리·포스트 포함 차트 직전 봉 근사 — 명기) |갭| ≥ 0.5% → 가중 0.5 표.
- **ⓑ DC-NF · ⓒ DC-PM × 바스켓 부호**: v2 동일.
- **ⓓ' P1 유럽 다창**: ASML.AS·IFX.DE·STMPA.PA 현지 5분봉(8/22 실측 가용) — 세션 변화율 |≥0.3%| 방향, 단 종반 30분이
  반대로 ≥0.15% 기울면 기권. (v2의 "세션 변화율 근사"를 실제 종반 창으로 대체)
- **ⓔ' 이벤트 2등급 — 전부 자동 감지, 수동 입력 없음**:
  - 1급 = 기존 자동(FOMC·CPI·고용 캘린더 + 야후 실적 타임스탬프 15종) **+ 바스켓 구성(NVDA·MU·AMD·SOXL)·삼전·하닉·AAPL·TSM 실적** → 방향 예측 무효화.
  - 2급 = FRED 발표 캘린더 ★3 이상 2차 지표(PCE·GDP·실업수당·ISM 등, CPI·고용·FOMC 제외) → **확신도 −0.25/건** (무효화 아님).
- **ⓕ 매크로 변화율**: v2 동일.
- 출력: 표 가중합(갭 0.5) net ≥ 2 → 방향, 확신도 = |net|/4 − 2급 감점.
