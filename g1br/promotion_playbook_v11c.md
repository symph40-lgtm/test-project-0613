# v1.1c 승격 전환 플레이북 (발주자 지시 2026-08-20 밤 '적용 가속' §4 — 사전 문서화)

목적: 심사 통과 → 발주자 승인 → **당일 반영** (전환 지연 제로화). 아래 절차는 코드가 이미 지원한다
(2026-08-20 밤 준비 배포) — 승인이 떨어지면 스크립트 1회 실행으로 끝난다.

## A. R1 챔피언 교체 (v1.1c = nf 5번째 전문가 편입)

**승인 시 실행**:
```bash
npx tsx scripts/promote-v11c.ts --r1 [--symbol 000660]   # 종목 지정 없으면 두 종목 모두
```
스크립트가 하는 일 (상태 수술 — g1b_state):
1. **가중 이관**: state.hedge_w ← state.challenger_v11c.hedge_w (nf 포함 — 심사 시점의 학습된 발언권 그대로).
2. **마커**: state.promo_v11c = { at: 승격일 } — 이후 R1 결합·일일 학습이 nf 전문가를 포함해 돈다.
3. challenger_v11c 기록은 **동결 보존** (삭제 금지 — 심사 증거).

서비스 동작 (배포돼 있음):
- promo_v11c 존재 시 R1 챔피언 결합 = nf 포함 전문가 집합. **이벤트 밤은 nf 제외**(심사 표본과 동일
  조건 유지 — 발주자가 달리 정하면 이 줄만 변경). 일일 학습(dailyUpdate)이 nf 가중을 자동 증감 (상한 0.7 헌법).
- r1.champion_pack = "pack_v1.1c(승격 M/D)" 기록 — 화면 가중 줄에 표기, 계기판 nf 리더보드는 이력으로 유지.
- 채점 회계: te_r1_pct 정의 불변 (새 챔피언의 TE). 승격일 이후 te_v11c_pct는 챔피언과 동일값이 되므로
  구 챔피언 대조가 필요하면 승격일 전 구간으로 판정.

## B. R2 이론가 교체 (v11c 잔차 판정 우세 시 — '적용 가속' §2)

**조기 상신 규칙 (사전 등록, 8/20 밤)**: R2 이중 잔차 **8회 기록 시점**에 v11c 이론가의 익일 채점
(|이론가 갭 − 실측 갭| 비교, labels.te_r2_champ_pct vs te_r2_v11c_pct) **우세가 명확**하면 이론가 교체
조기 상신 — 발주자 판정. "우세 명확"의 조작 정의(성적 확정 전 등록): **승 ≥6/8 그리고 개선 중앙값 > 0**
(상위 중앙값 규약). 계기판 r2_theory_early_review가 자동 표시.

**승인 시 실행**:
```bash
npx tsx scripts/promote-v11c.ts --r2 [--symbol 000660]
```
1. **마커**: state.promo_r2_v11c = { at: 승격일 } — 이후 R2 공식 잔차·신호·행동·채점(te_r2)이
   v1.1c 이론가 기준으로 산출되고, 구 이론가는 병행 기록으로 자리를 바꾼다 (이원 저장 유지).
2. R2 카드·리포트 3숫자 규격의 "이론가" = v1.1c 이론가, "병행" = 구 챔피언 이론가.

## C. 공통 원칙

- **되돌림**: 마커 제거 + (R1의 경우) 가중 원복은 g1b_state_snapshots 당일 스냅샷으로 — 상태 해시 검증 후.
- 전환은 판정 창 밖(라벨 창 이후 ~ 다음 R1 전, 즉 11:00~다음날 06:00)에 실행 — 당일 회차 혼선 방지.
- 전환 자체는 본판정 60일 검증의 "챔피언 정의 변경"이므로 **발주자 승인 문서(채팅 지시)가 선행 조건**.
- 계기판 표기: champion_pack 필드가 자동 반영 — 별도 수작업 없음.
