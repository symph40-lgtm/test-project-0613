## 3. 발주자 결정 필요 항목

1. **KRX 데이터 계정 발급 여부** (data.krx.co.kr — 무료 가입, `KRX_ID`/`KRX_PW` 환경 변수).
   pykrx 신버전은 지수 시세·미수정 주가·이벤트 API에 계정을 요구합니다(실측 확인).
   - 발급 시: KOSPI200 정식 시세(^KS200 결측 14일 해소) + 락일 이벤트 자동 수집
   - 미발급 시: ^KS200(결측 1.6%)으로 진행 + 락일 캘린더는 수동 관리 — 진행 가능하나 차선
2. **금리 소스 확정**: FRED 당일치 불가가 실측 확정됨 → b2·b3를 야후(^TNX + 2YY=F 검증 조건부)로 교체할지, FRED 전일치 정의로 갈지. (§2 함의 참조 — 권고: 야후 교체, 2주차에 2YY=F 품질 검증 후 확정)
3. **B등급 2종(u1 야간선물·u3 TAIFEX) 60일 로그 이관 확인** — 스펙 §2.4에 명시된 경로이나 "관측부 검증 축소"라는 결과이므로 확인 요청.
4. **b5·b6(세션 질 2종) 오프라인 제외 확인** — yfinance 일중 한도 실측 근거(위 표).
5. (선택) TAIFEX 애프터아워 CSV **수동 다운로드** 의향 — 공식 파일이 존재하므로 사람 손으로 받으면 u3 히스토리 일부 확보 가능. 자동화는 금지 범위라 발주자 작업이 됩니다.

## 3-부록. 발주자 결정 반영 (2026-08-09)

- **결정 1 (KRX 계정)**: 발주자가 기존 가입 가능성 언급 — 단 `.env.local`에 `KRX_ID`/`KRX_PW` 없음(전수 검색). **발주자가 두 키를 .env.local에 추가하면 fetch가 pykrx 지수로 자동 전환**, 그 전까지 ^KS200 폴백으로 진행 (양쪽 모두 구현).
- **결정 2 (금리 야후 교체) 확정**: 2YY=F 실측 — 2023-01-03~현재 903행, 결측 0, 레벨 4.15%(현물 2Y와 정합). ^TNX 902행 결측 0. **b2·b3 소스 = ^TNX·2YY=F (당일치 07:15 가용), FRED는 검증 병행.** 주의: 2YY=F는 선물 수익률이라 현물 대비 미세 베이시스 존재 — 변화량(Δ) 사용이므로 영향 미미, 2주차 회귀에서 FRED 전일치와 대조 예정.
- **추가 발견 (Δfx 절단)**: KRW=X **일봉**은 London 자정 마감 = KST 08~09시 완성 → **R1 07:15 기준으로는 당일봉이 룩어헤드**. b4는 ①전일봉 사용 또는 ②시간봉(60m, 2024-08 이후만 가용) 중 택일 필요 — 2주차 결정 사항으로 이관, 1주차 패널은 일봉 Δfx에 `available_by_0715=False` 표기.

## 4. 기타 실측 기록

- pykrx 수정주가 확인: `adjusted=False`(미수정) 엔드포인트가 KRX 계정 요구로 실패해 수정/미수정 대조는 불가. 대신 수정주가 시계열의 일일 변동 이상치 검사로 대체 — ±20% 초과가 2026-07-31 단 1건(양 종목), 네이버 독립 소스와 가격 일치 확인 → **실제 시장 급등이며 조정 오류 아님**. 기간 내 액면분할 없음(삼전 2018).
- KOSPI 서킷브레이커급 변동 구간(2026-03, 06~07월)이 검증기간에 포함됨 — 스펙 §3.3 대변동 레짐 표본에 유리, 단 §8-3(레짐 편중) 점검 대상.
- `KRX 로그인 실패` 경고는 pykrx import 시 무해하게 출력됨(종목 시세는 무계정 정상 동작).
