# NM3 통합 스펙 v0.1 — 신모델(하닉·삼전·SOXX)의 전문가 이론 기반 차세대 사양

**작성 기준**: 하닉 가이드(2026-08-01, 227일), 삼전 v2(2026-08-02, 232일), SOXX v2(2026-08-06, 246일)
**설계 원칙**: 챔피언(현행 3모델)은 그대로 둔다. 본 스펙의 모든 제안은 **챌린저**이며, 각자의 게이트를 사전등록 후 통과해야만 승격한다. 누적 시도 수 비례 최소 마진 요건 적용 — 이미 320+30+다수 조합이 같은 데이터를 통과했으므로 마진 요건은 높게 시작한다.

# PART 0. 진단 — 현행 골격의 이론적 지위

현행 3모델은 독자 설계지만, 전문 트레이딩의 검증된 계보와 정확히 겹친다. 이것은 좋은 소식이다 — 골격을 갈아엎을 이유가 없다는 뜻이다.

| 현행 요소 | 전문가 계보 | 이론적 근거 |
|---|---|---|
| 피셔F의 OR 박스 돌파 | **Opening Range Breakout** — Toby Crabel *Day Trading with Short Term Price Patterns*, 최근 실증(Zarattini–Aziz의 QQQ/TQQQ ORB 연구) | 개장 후 첫 구간은 가격발견(price discovery) 구간 — 그 범위의 이탈은 당일 방향성 경매 개시의 신호. "박스 전 갭=위치, 후 갭=신호" 구분은 경매이론의 가치영역 재설정과 동형 |
| 창판정 (6봉 누적 순전진 ≥ 평소 흔들림×2.5) | **Range Expansion / 변동성 돌파** — Crabel의 NR·확장일, Raschke의 "모멘텀이 가격에 선행한다" | 정상 노이즈 대비 k×σ 초과 변위 = 정보 도착의 통계적 검출. 눈금(30봉 평균폭×0.5)의 자동 적응은 변동성 정규화 그 자체 |
| "나중 신호가 심판" (E1) | **베이지안 갱신** | 신규 정보 도착 시 사후확률 갱신 — 시간상 뒤 신호가 더 많은 정보를 담음. 두 모델 공히 성립하고 주체만 다른 것도 정합적 |
| 정찰–검증 분업 (빠른 신호+느린 신호) | **fast–slow 필터 분리**, 편향–분산 트레이드오프 | "검증관은 느려야 정확하다"(삼전 §7)는 실측은 느린 필터의 저분산 성질의 재발견 |
| 4단 사다리 30→70→100 | **확신 비례 피라미딩**, 부분 Kelly | 검증 통과량에 비례한 노출 — 사다리 t=3.5, "에지는 방향이 아니라 비중 배분"이라는 결론은 Kelly 계열 문헌의 핵심 명제("사이징이 알파다")와 일치 |
| 손익비 1.95 / 승률 52% | 추세추종의 고전 손익 구조 | 승률이 아닌 왜도(skew)로 버는 구조 — CTA/추세추종 실증과 동형 |
| SOXX 1박 (+53.3%p, 전체 38%) | **오버나이트 프리미엄** — Cooper–Cliff–Gulen(장외시간 수익률), Lou–Polk–Skouras *A Tug of War* | 주식 수익의 대부분이 종가→시가 구간에 실현된다는 견고한 실증. 1박이 최대 수익원이라는 발견은 문헌과 정확히 일치 — 우연이 아닐 가능성이 높음 |
| 서킷브레이커 (컷 클러스터링 26→44%) | **변동성 군집** — ARCH/GARCH (Engle), Mandelbrot | 손실(=고변동)은 몰려서 온다. 컷 후 노출 축소는 조건부 변동성 예측의 규칙화 |
| 갭 규칙 (≥4% 정찰 절반) | 갭 크기별 지속/소진 실증 | 대형 갭 = 이미 소진된 정보 + 변동성 상향 — 노출 축소가 정석 |
| 동전 대조군·무신호 상승편향 대조군 | **벤치마크 통제** | +71.8(동전), +51.6(무신호 롱)을 놓고 초과분만 실력으로 보는 태도는 학술 검증의 알파 정의와 동일 — 이미 반쯤 전문가 방법론 |

**결론**: 골격 유지. 아래 PART 1의 취약점만 전문가 표준으로 보강한다.

# PART 1. 전문가 기준 취약점 진단 (보강 대상)

### D1. 다중검정 인플레이션 (가장 심각)
하닉 320조합, 삼전 30여 조합, SOXX 격자 3축 + 기각표의 수십 개 아이디어가 **같은 227~246일 표본**에서 시험·선택되었다. 선택된 최종 사양의 t=3.5는 선택 편향으로 부풀려진 값이다 — 삼전 문서 스스로 "운 몫이 섞여 있을 수 있다"고 쓴 그 문제의 정량화가 없다. 246일은 반도체 강세 구간이기도 하다(12/12개월 흑자의 배경).

### D2. 사이징이 확신 비례일 뿐 변동성 비례가 아님
사다리는 "얼마나 검증됐나"에 비례하지만 "오늘 시장이 얼마나 위험한가"에는 둔감하다. 배정 100% × 레버 2~3x 고정. 전문 운용의 표준은 **변동성 타게팅**(노출 ∝ 목표변동성/실현변동성) — 서킷브레이커·갭 규칙이 이미 그 방향의 이산 근사임이 실측으로 확인됐으므로, 연속형으로 일반화할 근거가 자체 데이터에 있다. (주의: 하닉 §6.4가 기각한 것은 **방향** 기반 조절이다. 변동성 기반은 별개 가설.)

### D3. 포트폴리오 관점 부재
하닉·삼전·SOXX는 같은 반도체 콤플렉스다. 세 모델이 각자 100%를 쓰면 상관 높은 레버리지 베팅이 KST 09:00~익일 05:00에 릴레이로 이어진다. 계좌 전체의 동시 노출 상한, 일일 손실 한도(킬 스위치), 세션 간 리스크 이월 규칙이 없다.

### D4. 꼬리 리스크의 표본 의존
SOXX 프리장 무스탑의 근거는 "57일 최악 -1.67%" — 57일 표본의 최악값으로 무한 꼬리를 막을 수 없다. 1박 재난선 -5%도 이벤트 밤(FOMC·CPI·NVDA/AVGO 실적)과 평상 밤을 구분하지 않는다. 전문 리스크 관리는 표본 밖 꼬리를 **이벤트 달력과 조건부 규칙**으로 다룬다.

### D5. 비용 미반영 (SOXX)
미장 편도 0.07% 미차감. 진입+청산+전환이 잦은 구조에서 246일 누적 비용은 두 자릿수 %p 규모일 수 있다 — +141.6의 실질치가 미확정. 국장(0.01% 반영)과 기준이 다르다.

### D6. 사다리의 수동 설계
30→70→100 단계와 문턱은 손으로 만든 확신 함수다. 훌륭한 출발점이지만, 판정 시점에 이미 아는 특징(갭 크기, r10 대비 강도, 시각, 스트릭 품질, 서킷 상태)으로 P(승) 자체를 추정해 비중으로 번역하는 일반화(메타 라벨링, López de Prado)가 존재한다.

### D7. 사내 시너지 미활용
G1B(FairGap)가 밤새 하닉·삼전의 익일 갭을 σ_night 단위로 추정하고 있는데, 신모델의 갭 규칙은 실현 갭 크기(≥4%)만 본다. 예측기와 판정기가 서로를 모른다.

# PART 3. Layer V — 검증 인프라 (최우선, 판정 불변)

현행 성능 수치를 "믿을 수 있는 수치"로 바꾸는 레이어. 규칙을 하나도 바꾸지 않으므로 게이트 없이 즉시 구축한다.

### V1. 시도 대장 (Trial Ledger)
지금까지 같은 표본에서 시험한 모든 조합(320+30+격자+기각표 항목)을 소급 집계해 `trial_ledger.json`에 기록. 이후 모든 신규 백테스트는 실행 전 대장에 등록해야 결과가 유효 — R3 사전등록 순서 강제와 동일 메커니즘.

### V2. 수축 샤프 (Deflated Sharpe Ratio)
Bailey–López de Prado의 DSR: 시도 횟수 N, 수익 분포의 왜도·첨도를 반영해 "N번 시험 후 최선을 골랐을 때 우연히 나올 최대 샤프"를 차감한 유의성. 세 모델 각각에 대해 대장의 N으로 DSR 산출 — **DSR > 0.95 신뢰수준**이 향후 모든 승격의 공통 관문. 참고치로 White Reality Check/Hansen SPA(전체 시도 분포 대비 최선 전략의 우월성 검정)를 병기.

### V3. 워크포워드 재검
현행 수치는 전 구간 일괄이다. 6개 폴드(약 40일 단위)로 나눠 **앞 폴드들로 상수 확정 → 다음 폴드에서만 채점**을 롤링. 캘리브레이션 대상 상수(눈금 배수, 오프셋, 스탑 폭)만 재적합하고 구조(분업·심판·사다리)는 고정. 산출: 폴드별 성과 분산, 전반/후반 안정성(하닉 "최근일수록 강함"이 워크포워드에서도 성립하는지).

### V4. 벤치마크 초과분을 주지표로
공식 성적표를 절대 누적이 아니라 **초과 성과**로 전환: 하닉·삼전 = (모델) − (무신호 09시 롱+동일 스탑), SOXX = (모델) − (매일 매수 후 1박). 반도체 강세 베타를 벗겨낸 값이 진짜 알파 — 12/12개월 흑자 같은 수치의 착시를 구조적으로 제거.

### V5. 페이퍼 궤도 게이트의 통계화
현행 "60일 페이퍼가 궤도 안인지"를 정식 SPRT(순차확률비검정) 또는 최소한 신뢰대역으로: 궤도 기대 일당 μ_bt와 실측 분산으로 60일 누적의 90% 대역을 사전 계산해 게시 — 이탈 판정이 눈대중이 아니라 대역 이탈로 자동화.

# PART 4. Layer R — 리스크 오버레이 (챌린저 4종)

### R1. 변동성 타게팅 (연속형 서킷브레이커)

```
sizing_mult(t) = clip( σ_target / σ_ewma(t),  0.5,  1.0 )
σ_ewma: 본주(또는 SOXX) 일간수익률 EWMA(λ=0.94, RiskMetrics 표준), 전일까지만 사용
σ_target: 백테스트 기간 σ_ewma의 중앙값 (초기값 — 캘리브레이션 대상)
적용: 사다리·단일 트랜치의 모든 단계 비중에 곱산 (상한 1.0 — 저변동일 증액은 하지 않음, 단방향)
```

- 기존 서킷브레이커·갭 규칙과 **병존** (이산 장치는 헌법 유지, R1은 그 위의 연속 감쇠)
- 사전등록 기대: 누적 수익 소폭 감소(-5~-15%p 허용), MDD·최악일 20%+ 개선, 손익비 불변. 수익 감소가 허용 범위를 넘으면 기각하고 기록
- 하닉 기각표의 "당일 변동 레짐 보정"과의 구분: R1은 **전일까지의** EWMA만 사용 — 기각된 것은 당일 지표(반전 사실과 오염)이며, 채택된 isHighVolDay도 전일 지표다. 정합.

### R2. 포트폴리오 노출 상한 + 킬 스위치

- **동시 노출 상한**: 계좌 레버리지 환산 노출(국장 2x + 미장 3x)의 합 ≤ L_max (초기 3.0x — 즉 SOXX 1박 보유 중이면 다음날 국장 진입 비중이 자동 감산)
- **일일 손실 한도**: 계좌 -4%(캘리브레이션 대상) 도달 시 당 세션 신규 진입 금지 (보유·스탑은 유지 — 강제청산 아님)
- **주간 드로다운 동결**: 주간 -8% 도달 시 다음 주 전 모델 정찰 비중 절반 (서킷브레이커의 계좌 레벨 버전)
- 근거: 세 자산의 일간 상관을 백테스트 기간에서 실측해 문서에 명기 — 상관 0.6 이상이면 "세 모델 = 사실상 한 베팅의 시차 분산"임을 성적표에 병기

### R3. 이벤트 달력 필터 (SOXX 1박 한정)

- 이벤트 정의: FOMC 발표일 밤, CPI 발표 전야, NVDA·AVGO·TSMC·MU 실적 발표 밤, 트리플위칭 전야 (달력은 분기별 수동 갱신 — 자동화 금지, 헌법상 인간 관리 항목)
- 규칙(챌린저): 이벤트 밤은 1박 자격이 있어도 **MOC 청산** (또는 재난선을 -3%로 조임 — 두 안을 ablation)
- 사전등록: 246일 중 이벤트 밤의 1박 손익을 분리 집계해 등록. 이벤트 밤이 실측 흑자면 필터를 기각하고 "이벤트 밤도 에지"로 기록 — 결과를 미리 정하지 않는다

### R4. 꼬리 보험 스탑 (프리장·표본 밖 전용)

- SOXX 프리장에 **재난선만** 신설: SOXX -4% (3x -12%), 지정가 아닌 스탑마켓
- 논리: 백테스트에서 한 번도 안 걸리는 폭이면 in-sample 비용 = 0이고 표본 밖 꼬리만 자른다 — "실측 열위"였던 -1~-6% 전 폭과 달리 이 폭은 실측상 **중립**이어야 정상. 백테스트 재실행에서 1회라도 걸려 수익을 깎으면 폭을 넓히거나 기각
- 같은 원리로 하닉·삼전 프리장 판정 실행분에도 재난선 존재 여부 점검

# PART 5. Layer C — 비용 정합 (즉시 적용)

- SOXX 백테스트를 편도 0.07% + 보수적 슬리피지(프리장 체결 스프레드 실측 중앙값, 저유동 프린트 필터 이후 기준)로 **전면 재계산** — +141.6의 비용 차감 후 수치를 공식 수치로 교체

# PART 6. Layer M — 메타 라벨링 사다리 (챌린저, 하닉 우선)

### M1. 개념
López de Prado의 메타 라벨링: 1차 모델(현행 판정)은 **방향만** 담당, 2차 모델은 "이 판정이 맞을 확률"을 추정해 **비중만** 담당. 현행 4단 사다리는 이 구조의 수동 근사이므로, 일반화 경로가 자연스럽다.

### M2. 사양
- 학습 표본: 하닉 227일의 F 판정 건 (판정 시점 스냅샷)
- 특징 (판정 시점에 이미 아는 것만 — lookahead assert): 갭 크기·부호, r10 대비 돌파 강도, 판정 시각, 완충 구간 여부, 서킷 상태, 전일 컷 여부, σ_ewma 백분위, OR 폭/r10 비율, 창판정 기존재 여부
- 모델: 로지스틱 회귀 **고정** (표본 227건에 트리·부스팅 금지 — 과적합 방지를 모델 클래스 제약으로), L2 정규화, 폴드 간 purge 1일
- 출력 → 비중: p<0.45 → 15% / 0.45~0.55 → 30% / 0.55~0.65 → 70% / >0.65 → 100% (경계는 현행 사다리 단계와 정합하게 고정 — 튜닝 금지)
- **게이트**: 워크포워드에서 현행 사다리 대비 초과 +10%p 이상 **그리고** 최악일 악화 없음 그리고 DSR 관문 통과. 미달 시 기각하고, 계수 부호가 현행 사다리의 논리(진행성·검증 신호의 양의 기여)와 정합하는지만 참고 기록
- 삼전 적용은 하닉 통과 후에만 검토 — 삼전은 "증액 시점엔 알짜가 끝나 있다"는 구조적 반례가 실측돼 있으므로, 판정 **시점의** 비중 차등(사후 증액 없음)만 후보

# PART 7. Layer G — G1B 갭 연동 (챌린저, 사내 시너지)

### G1. 갭 규칙의 예측화
현행: 실현 갭 ≥4% → 정찰 절반. 제안: G1B FairGap의 **전야 예측치**를 병용 —

```
예상갭_σ = |FairGap 예측| / σ_night
전야 23:00 기준 예상갭_σ ≥ 2.0 → 익일 "갭 경계 예보" 문자 (정찰 절반 예고)
실현 갭과 예측의 괴리 ≥ 2σ_night → "예측 밖 갭" 태그 — 당일 정찰 절반 + 경계 (예측이 못 본 정보가 도착했다는 뜻)
```

- 1차는 **문자·태그만** (판정·비중 불변). 60일 태그 축적 후, 태그일의 실측 성과가 유의하게 나쁘면 비중 규칙으로 승격
- 사전등록: "예측 밖 갭" 일의 컷률 > 평상일 컷률 (G1B가 신모델에 정보를 준다는 존재 증명). 무차별이면 연동 기각 — 두 시스템은 독립 유지

### G2. 역방향 검증
신모델의 저녁 SOXX 신호로 국장 갭을 예측하는 아이디어는 이미 기각됐다(일치 40~55%). G1은 그 역방향(전용 갭 예측기 → 국장 리스크 조절)이므로 기각 사례와 다름을 명기 — 단 같은 함정(밤 정보의 겉보기 상관)을 피하기 위해 G1B의 기존 게이트 성적을 전제 조건으로 링크.

# PART 8. 성능 평가 프로토콜 (기존 데이터로 즉시 실행 가능)

### 8.1 실행 순서 (순서 강제 — 파이프라인이 타임스탬프 검사)

```
P0  trial_ledger 소급 구축 (V1)
P1  Layer C 재계산 → 비용 차감 공식 수치 확정 (SOXX 중심)
P2  V4 벤치마크 초과분 산출 → 3모델 공식 성적표 교체
P3  V2 DSR / SPA 산출 → "현행 챔피언의 통계적 지위" 문서화
P4  V3 워크포워드 → 폴드 안정성 리포트
P5  사전등록 커밋 (아래 8.3 — P6 실행 전 필수)
P6  챌린저 ablation: (챔피언) → (+R1) → (+R1+R2) → (+R3) → (+R4) → (+M) → (+G)
     각 단계: 초과수익, MDD, 최악일, 컷률, 손익비, 비용, DSR
P7  게이트 판정 → 승격/기각/기록 → NM3 v0.2
```

### 8.2 지표 정의
- 주지표: **초과 누적**(V4 기준) 및 **초과의 DSR**
- 리스크: MDD, 최악일, CVaR(5%), 최장 연속손실, 컷률
- 안정성: 폴드 간 성과 표준편차 / 평균 (V3), 페이퍼 궤도 대역 (V5)
- 모든 챌린저는 "수익 증가"가 아니라 **"위험조정 초과의 개선"**으로 심판 — R 레이어는 수익이 줄어도 통과할 수 있고, M 레이어는 수익이 늘어도 DSR 미달이면 기각된다

### 8.3 사전등록 목록 (P5에서 수치 확정, P6 전 커밋)
- R1: MDD·최악일 개선폭 하한 / 수익 감소 허용 상한
- R2: 세 자산 상관 실측치, L_max 발동 빈도 예상 범위
- R3: 이벤트 밤 1박 손익 분리 집계치 (결과 확인 전 등록 — 필터 채택/기각 기준 명문화)
- R4: 재난선 in-sample 발동 0회 (1회 이상이면 폭 재설정)
- M: 초과 +10%p 하한, 계수 부호 정합 목록
- G: "예측 밖 갭" 일 컷률 > 평상일 (미달 시 연동 기각)
- 공통: DSR > 0.95 관문, 기대치 이탈은 조정이 아니라 이탈로 기록

## V-C. 판정 — "이것으로 새로 코딩하면 되나"

- **Layer V·C (P0~P4)**: 코딩 가능 수준이었고 **본 주석으로 실행 완료**. 공식 성적표 교체(비용 차감·초과 기준)는 발주자 승인 사항.
- **Layer R·M·G (P5~P7)**: 스펙만으로 코딩 불가 — 함께 전달된 평가와 동일 판단. 코드가 요구하는 미정의: R1 σ_ewma 확정 시각·적용 시점(lookahead 경계), R2 세션 중첩 구간(SOXX 1박 보유 중 국장 개장)의 노출 합산, R4 주문 유형·발동 후 재개, M 특징 스냅샷 스키마·purge, G의 G1B 스냅샷 시각·인터페이스, P5 타임스탬프 강제 위치. **PG-1 IMPL_SPEC 수준의 구현명세(데이터 계약·평가 순서·불변식·DoD)가 선행 조건.**
- **우선순위 시사 (P1·P3 결과 반영)**: ①비용 귀속상 회전 절감 검토(특히 삼전 E1·SOXX 전환)가 R1 변동성 타게팅과 최소 동순위 ②DSR 전패로 V5(페이퍼 궤도 통계화)가 챌린저보다 급함 — 라이브 아웃오브샘플이 유일하게 선택 편향 없는 증거이므로.
