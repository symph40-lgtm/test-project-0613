## §B. W1 — V5 페이퍼 궤도 통계화 (전체 0순위)

### B1. 데이터 계약
- 입력: 위 채점 키 3종의 확정 행만 (`pend=true` 1박 미확정 행 제외 — 확정 시점에 재계산).
- 기준 궤도 (D-1: 비용 차감 수치로 재산정): μ_bt·σ_bt는 scripts/nm3-v.ts의 일간 순수익 시계열(기본 슬리피지)에서 산출해 **본 문서 부록에 상수로 고정 기록** (하닉·삼전 = 본주 %p/일, SOXX = SOXX %p/일 — 채점 p와 동일 단위). 초과 기준(μ_ex) 병기.
- 신규 모듈: `lib/predict/nm3V5.ts` — 순수 함수 `trackBand(rows, mu, sigma)` / `sprt(rows, mu0, mu1, sigma, alpha, beta)`. 상태 저장 없음(매 결산 시 전체 재계산 — 결정론).

### B2. 판정 장치 정의
1. **신뢰대역**: 누적 T일 시점 대역 = T·μ_bt ± z·σ_bt·√T, z ∈ {1.645(90%), 2.576(99%)}. 페이퍼 누적이 90% 하단 이탈 = "주의", 99% 하단 = "재검 소집" (상단 이탈은 정보로만 — 과성과도 기록).
2. **SPRT**: H0: μ=μ_bt vs H1: μ=0, 공통 σ=σ_bt, α=β=0.1.
   `LLR_T = Σ_t [ln f(x_t; 0, σ) − ln f(x_t; μ_bt, σ)] = Σ_t [(x_t−μ_bt)² − x_t²] / (2σ²)`
   판정: LLR ≥ ln((1−β)/α)=+2.197 → **H1 수용(에지 소멸 의심 — 중단·재검)** / LLR ≤ ln(β/(1−α))=−2.197 → **H0 수용(궤도 유지 — 승격 근거 충족)** / 그 외 **계속**. 60일 내 미종결 시 연장이 기본값(조기 승격은 SPRT H0 수용으로만 — v0.2 §4).
3. 결산 문자 병기 (1줄): `궤도: 누적 +X.X (대역 내 zZ.Z) · SPRT 계속(LLR -1.2)` — 수동 눈대중 판독 폐지.

### B3. 불변식·테스트·DoD
- 불변식: (i) 입력 행 불변 — V5는 채점을 읽기만 (ii) 같은 rows → 같은 판정 (결정론) (iii) μ_bt·σ_bt는 상수 — 코드에서 재추정 금지(변경은 문서 개정으로만).
- 테스트 (합성 검정): μ=μ_bt 정규 난수 1,000경로×60일 → H1 오수용률 ≈ α(±3%p) / μ=0 경로 → H0 오수용률 ≈ β(±3%p) / 대역 이탈률 ≈ 10%·1%(±2%p). `scripts/nm3-v5-synth.ts`.
- DoD: ①3모델 결산 문자에 1줄 병기 가동 ②합성 검정 통과 ③기존 페이퍼 누적분 소급 재계산 결과를 발주자 보고(현재 위치 확인) ④채점 배열 장기 백업 경로 확정(120일 절단 대비).

## §C. W2 — 규칙별 순기여 재심 (회계 — §0 허용 용도 (a))

### C1. 귀속 방법론
- scripts/nm3-v.ts 확장: 레그 미러에 규칙 태그를 달아 규칙별 {귀속 총이익, 변 수, 귀속 비용(기본 슬리피지), 순기여} 산출.
- 재심 대상 규칙: 삼전 E1 역진입(이견일 2번째 왕복) · SOXX E1 전환 · SOXX 인버스 보호청산 · 하닉 사다리 각 단(정찰 30/증액 70·100/이견 재진입) · 1박(별도 회계 — 진입 변은 낮 규칙에, 청산 변만 귀속).
- 판정 등급: 명백 양(유지) / 경계(관찰) / 명백 음(**제거 후보 지정**) — 경계 기준: |순기여| < 귀속 비용의 30%.

### C2. 사전등록 (재심 스크립트 실행 전 본 절에 기입)
- 예상: 삼전 E1 = **양수 유지** (이견일 +18.1%p vs 이견일 왕복 비용 추정 ~74일×2왕복×비용) — **최대 관심 항목** / SOXX 전환(E1 59일) = 양수 / 인버스 보호 = 경계 / 사다리 증액 = 양수 / 하닉 이견 재진입 = 양수.
- 이탈은 이탈로 기록. 등급이 "명백 음"이어도 **즉시 제거 금지** — 제거 후보 지정 후 variant 열(예: 삼전 `pNoE1`, SOXX `pNoRev`)을 채점에 추가, 페이퍼 병행 채점 → 전향 성적으로만 확정 (§0이 제거에도 적용).

### C3. DoD
①귀속표 문서화(본 문서 부록) ②제거 후보 목록 + 각 후보의 variant 열 가동 ③사전등록 대비 이탈 기록.

### D2. R4 꼬리 보험 재난선 (프리장)

- 발동 후: 당일 재진입 금지, 익일 정상 재개. 발동 = 통계 외 사건이므로 즉시 문자 + 재검 소집.
- 하닉·삼전 프리장 실행분(창판정 프리장 진입) 재난선 존재 점검: 현행 국장 낮 스탑(-2.5/-1.5%)이 프리장 구간에도 감시되는지 확인 후, 미감시면 동일 원리(발동 0회 폭)로 신설 검토.
- 테스트: 재계산 스크립트에 발동 카운트 assert(=0), 재난선 폭 > 낮 스탑 폭 불변식.
- DoD: ①상관표·노출 분포·차단 일수표 제출 ②L_max 발주자 확정 ③재난선 0회 검증 ④신모델 가이드에 헌법 문안 편입(인간 승인+쿨다운+드로다운 동결 조건).
