# 삼전 신모델 가이드라인 — 모멘텀 창 + 피셔F 전환 (v2)

작성 2026-08-02 (8/2 주말 설계·실측 세션 총정리) · 근거 백테스트: 삼전 232일(2025-08-19~2026-07-31) · 수수료: 국장 0.01%/편도

> **한 줄 요약**: 빠른 신호(6봉 모멘텀)로 초입에 100% 올라타고, 틀리면 작게(-1.5%) 끊기며, 느리고 신중한 신호(피셔F)가 반대를 확인하는 순간 통째로 갈아탄다. **하닉과 정반대의 역할 배치** — 하닉은 피셔가 정찰하고 형태가 검증하지만, 삼전은 모멘텀이 정찰하고 피셔가 검증한다.

**이 문서를 읽는 법**: §1~2는 "무엇으로 판정하는가", §3은 "매일 무엇을 하는가"(실전 규칙과 하루 예시), §4는 "왜 이 구조인가"(하닉과의 대비), §5는 "문자가 오면 할 일", §6은 "성적표", §7은 "버린 아이디어 목록"(재론 방지), §8은 "일정"이다.

## 1. 시스템 개요

- **적용 종목: 삼성전자 전용**. 판정은 본주(005930) 가격으로 하고, 실제 매매는 레버리지/인버스 ETF 2배물로 한다. 본주 1% 움직임 = ETF 약 2% 손익.
- **두 신호의 분업** (하닉과 역할이 반대라는 것이 핵심):
  - **창(6봉 모멘텀) = 정찰병**. 직전 6개 1분봉의 누적 전진이 평소 흔들림의 2.5배를 넘으면 판정. 거의 매일 판정하며 첫판정 중앙 09:00 — 피셔보다 44~76분 빠르다. 역할: **초입에 올라타기**.
  - **피셔F = 검증관**. 기존 삼전 F 그대로(박스 이탈 유지 확인, 완충 ×3·09시 게이트로 신중). 첫확인 중앙 09:44. 이견 상황에서 옳을 때가 많다(이견일 실측: 창 방향 사실상 전패, F 방향 +18.1%p). 역할: **틀린 레그 끊고 뒤집기**.
- **기존 삼전 피셔 3계층(F/M/본 20/30/50)은 그대로 돌지만 시범 중 대조용** — 문자에 각주로 표기된다.
- **비중: 판정 시 100% 단일 트랜치** (사다리 없음 — 50% 정찰 분할은 실측 열위 §7).

## 2. 판정 엔진 상세

### 2.1 창 판정 (6봉 누적 순전진) — 진입 신호

조건은 단 하나다:

> **직전 6봉(5쌍) 동안 몸통중간(시가·종가의 평균)이 "눈금 × 5" 이상 실제로 전진했는가.**

- **눈금** = 직전 30봉 평균 고저폭의 절반. "요즘 1분에 보통 흔들리는 폭의 절반"으로, 조용한 날엔 작아지고 요동치는 날엔 커져 자동 적응한다. 쌍당 눈금 1개 = 평균 기울기 45°에 해당.
- 6봉 요구 총량 = 평소 1분 흔들림의 **2.5배**를 6분 안에 순전진 — "짧고 굵은 모멘텀 폭발"만 통과한다.
- 형태 조건(시가연결·되돌림·두께·양봉·각도)은 **전부 없음** — 삼전에서는 부가가치가 없거나 해롭다는 4중 실측(§7).
- **일 최초 풀판정만 진입 신호**다. 이후의 창 전환(반대 판정) 신호는 **무시** — 실측상 노이즈(전환청산 -3.5%p).
- 창 크기는 사용자 확정(8/2): **6봉 시범** — 4~6봉이 +101~105 평원이나 6봉이 컷일 최저(88)·첫판정 09:00(프리장 실행 문제 해소). 4봉·5봉은 채점으로 병행 추적.

### 2.2 피셔F — 전환(청산·역진입) 신호

삼전 라이브 F에 **0930 박스 전환(rebox)** 하나만 더한 것을 쓴다: 프리장 08:00~15 박스 OR로 시작 · 오프셋 0.05×r10 · 확인 4봉 · 강돌파 0.075 · 장초반 완충 ×3(~10:30) · 확인은 09:00부터 · **09:45부터는 09:30~45 박스로 앵커 전환**(상태 승계 — 하닉 F·M 시범과 동일 박스). rebox 단독 실측: F 단독 +61.9→+79.9·v2 +105.4→+112.8 (10:00 전환 변형은 심판 지연으로 열위 기각). **당일 첫 확인 하나만** 본다 — 이후 F의 전환·재확인은 무시.

- F가 창과 **같은 방향** 확인 → **"검증 통과 — 보유 지속" 확인 문자** 발송 후 종가까지 보유
- F가 창과 **반대 방향** 확인 → **전량 청산 + 반대 방향 100% 역진입**
- ⚠주의: rebox는 유효하지만, 확인봉 단축·완충 완화까지 얹는 개조는 실측 악화 — **검증관의 신중함(확인 4봉·완충)은 유지**(§7)

## 3. 최종 규칙 세트

```
[진입]
창 6봉 첫판정      → 그 방향 100% (스탑 본주 -1.5% = ETF -3%, 앵커 = 판정 시점 가격)
프리장 판정일      → 문자에 "09:00 개장가로 실행" 지침 동봉
F가 창보다 먼저 선 날(실측 0~1%) → 관망 (신모델 무진입)

[청산·전환 — 전부 자동 규칙]
스탑              → 트랜치별 진입가 -1.5%(본주). 컷 후 재진입 없음 — F 전환 문자만 대기
F 반대 확인       → 전량 청산 + 반대 100% 역진입 (앵커 = F 확인가·스탑 동일)
역진입 레그        → 스탑 -1.5% / 종가 청산 (그 후 추가 액션 없음)
종가              → 전 포지션 당일청산 (오버나이트 없음)

[무시하는 것] 창의 2번째 이후 전환 · F의 첫 확인 이후 전환·재확인 · 피셔M·본피셔 · 하닉 신호
```

### 하루 흐름 예시

**좋은 날 (공통 — 232일 중 129일꼴)**
09:00 창 상승 판정 → 레버 ETF 100% 진입, 스탑 -3% 설정 → 09:50 F도 상승 확인(문자 없음 — 검증 통과) → 종가 전량 청산. 초입부터 종가까지 통째로 먹는다. 이 케이스가 수익의 사실상 전부(+207.5%p/129일).

**반전의 날 (이견 — 74일꼴)**
09:05 창 상승 판정 → 진입 → 밀려서 09:40 스탑 -1.5% 컷 → 10:10 F가 **하락** 확인 → 전환 문자 → 인버스 100% 진입 → 종가 청산. 창의 손실은 -1.5%로 제한되고 F 역진입이 회수한다(+18.2%p/232일 = 이견일당 +0.25%).

**보험료 날 (창만 — 29일꼴)**
창 판정 후 F가 하루 종일 침묵 → 그대로 종가까지. 이런 날은 평균 손해(-20.1%p 합)지만 사전에 알 방법이 없다 — 모델의 예정된 비용.

## 4. 왜 이 구조인가 — 하닉과의 대비

| | 하닉 신모델 | 삼전 신모델(v2) |
|---|---|---|
| 유효 정보 | **형태** (6봉 계단의 질) | **속도** (6분 누적 전진량) |
| 정찰(빠른 신호) | 피셔F (09:33) | 모멘텀 창 (09:00) |
| 검증(느린 신호) | 형태 창판정 (09:53) | 피셔F (09:44) |
| 비중 운용 | 4단 사다리 30→70→100 | 100% 단일 (사다리 실측 열위) |
| 이견 규칙 | 나중 신호(창) 방향으로 교체 | 나중 신호(F) 방향으로 교체 — **같은 원칙** |
| 스탑(본주) | -2.5% | -1.5% |

- **삼전에서 형태가 안 통하는 이유**: 삼전의 예쁜 1분봉 계단은 "끝나가는 스퍼트의 마지막 모습"이다(판정 시점 = 스윙의 99% 지점 실측). 하닉의 계단은 "이어질 추세의 앞부분"이다(90% 지점 + 큰 절대폭). 형태를 조일수록 삼전은 더 늦어져 더 손해.
- **사다리가 안 통하는 이유**: 하닉은 검증 신호들이 조기 구간 안에 순차 도착해 증액이 유효하지만, 삼전은 검증자(F)가 44~76분 늦어 증액 시점엔 알짜가 끝나 있다. 절반 정찰(v3)은 좋은 날 수익(-81.8)을 나쁜 날 절감(+53)보다 크게 깎는다.
- **공통 원칙 "나중에 온 검증된 신호가 레그를 끊는다"** — 두 종목 모두 성립, 주체만 다르다.

| 스탑 도달 | 컷 발생 | ▶HTS 자동매도 확인만 — 재진입 금지, 전환 문자만 대기 |

**스탑 기준 정리**: 모델의 공식 기준은 **본주 -1.5%**(판정가 앵커·저가/고가 터치)이고, 문자에는 "ETF -3%(본주 XXX,XXX원)"으로 병기된다. HTS 자동매도는 **문자 수신 시점의 ETF 가격 기준 -3%**로 설정(매입가 기준이 아님 — 체결 지연 시 스탑이 위로 밀리는 사고 방지, 하닉 7/21 실측 원칙).
