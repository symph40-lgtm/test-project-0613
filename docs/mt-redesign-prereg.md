## 2. C3·C5·C7 배선표 (R4 — 재료 보강, 부품 수 동결 유지)

| 재료 | 배선 대상 부품 | 결합 방식 | 결측 시 |
|---|---|---|---|
| **C3 종반 강도** (CLV 20일 평균) | S2③ 폭·주도 유지 / S3④ 주도주 이탈 | fill을 `0.7×기존 + 0.3×CLV항`으로 합성. CLV항: S2③은 `ramp(CLV, 0.45, 0.65)`, S3④는 `ramp(0.55−CLV, 0, 0.2)` | 기존 fill 그대로 (가중 1.0) |
| **C5 수급 연속** (외인 연속일·감속률) | S1② No Supply / S3② Wyckoff 분산 | S1②: 외인 순매수 연속 ≥3일이면 `+0.15` 가산(상한 1) / S3②: 외인 순매도 연속 ≥3일이면 `+0.15` 가산 | 가산 0 (60일 이전 소급 구간은 전부 결측 → 3년 재채점에서 C5는 실질 0) |
| **C7 52주 고점 근접도** | S1④ 기반 상단 돌파 / S3③ UTAD | S1④: `high52 ≥ 0.9`이면 fill×1.2 (상한 1) — 고점권 돌파는 더 강한 증거 / S3③: `high52 ≥ 0.95`이면 UTAD fill×1.2 — 고점권 돌파 실패가 진짜 UTAD | 배율 1.0 |

배선 원칙: 새 부품을 만들지 않고 **기존 부품의 fill을 보강**한다. 재료가 없으면 원래 fill로 되돌아가므로 소급 구간과 라이브가 갈리지 않는다.

## 4. 재채점 방법 (1회)

- 구간: 3년(2023-05~2026-08) + 60일. 지그재그 15/20/25% 3벌. 포착 창 20일. 등급 구성비 병기.
- **채점 상태**: 승인 5건 중 "C1 등급 A/B 한정 활성화"와 "늑대소년 5부품 보조 증거 강등"은 **투표 경로에 반영한 상태**로 채점한다 (승인된 규칙이므로 이것이 이후 라이브 상태다). S4_1 가중 상향은 §4.2 재캘리브레이션 절차(월간·15일 섀도) 소관이라 **미반영**.
  - 늑대소년 강등의 조작적 정의: 해당 부품 fill은 **투표에서 0.5표**(단독 1표 불가), fillAvg(톤)에는 그대로.
  - C1 A/B 한정: 등급 C인 날의 C1 파생 4부품(S1_1·S2_4·S3_1·S4_2)은 **결측 처리**(투표 정원 축소 규칙 적용). 3년 소급 구간은 A/B가 1.7%뿐이므로 사실상 4부품이 빠진 상태의 채점이 된다 — 이 점을 결과에 명시.
- 비교 대상: **부검 시점 기준값**(A' 유지창, 3년·지그재그 20%): 포착 3/26 · 오탐률 56%.

## 5. 성공 기준 (기등록 유지 — 변경 없음)

**전부** 충족해야 성공:
1. 전환 포착 **≥ 8/26** (지그재그 20% 기준; 15%·25% 벌은 각 벌의 실제 전환 수 대비 **≥ 31%**로 환산 — 8/26의 비율)
2. 오탐률 **≤ 50%**
3. **3벌 모두** 1·2 충족
4. 톤 방향 적중 **54% − 2%p 이상** (톤 트랙 훼손 금지)

**부분 충족 = 미달.**

## 6. 미달 시 (발주자 판정 4)

- 전환 선언 트랙 **3년 표본 동결** — 스펙 §1.4·§1.5는 "동결(3년 표본 소진)" 표기로 개정 상신. 이후 개선은 **라이브 전진 검증(새 전환 표본)** 으로만.
- 톤 트랙·MT 표시 줄은 현행 유지 ("검증 미달" 꼬리표 포함).
- 전환 선언은 화면에서 내리고 로그(mt_days.transition)에만 남긴다.
