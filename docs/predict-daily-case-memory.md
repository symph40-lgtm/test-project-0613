# 일봉 정성 사례 메모리 — 기획 초안 (2026-07-28)

사용자 지시 (2026-07-28 저녁): "매일 당일 하락·상승 원인을 클로드가 취합·분석해서 누적하면
경험이 되니까, 레버리지·인버스 신모델·대가모델의 정규장·애프터장 일봉예측에 넣어서
유사한 사례가 있을 때 정성적인 비계량 일봉예측에 반영하는 모델을 만들고 싶어."

## 원칙 (프로젝트 공통 전례 준수)

- **판정 로직 불변으로 시작** — 환경 점수판과 동일한 2단계: ①표시·기록 전용으로 가동 →
  ②60일 라이브 채점 후 실측 근거가 있으면 점수 축으로 승격 (통일 규칙 적용).
- AI 정성 요약은 참고 정보로 표기하고, 계량 판정(미너비니·피셔·게이트)을 덮어쓰지 않는다.

## 구성

### 1. 수집 — 매일 원인 스냅샷 (15:05 판정 크론에 통합)

이미 수집 중인 것 재사용: macro(10Y·SOX·환율·DXY·WTI), kospiFlow(외인), newsRisk(AI 1일 1회),
envScore, 갭%·당일등락%·레짐(장세)·이벤트 D-n.

추가 수집 (AI 호출 1회 — 기존 newsRisk 호출에 프롬프트 확장, 비용 증가 없음):
- `cause_text`: 당일 등락 원인 3줄 요약 (예: "FOMC 경계 + 외인 현선물 동반 매도 + 엔비디아 급락 여파")
- `cause_tags`: 정형 태그 배열 (금리, 환율, 실적, 수급, 미국반도체, 지정학, 이벤트경계, 수동락 등)

### 2. 저장 — `predict_case_days` (마이그레이션 1개)

```
date PK · features jsonb(갭%·등락%·SOX·환율변화·외인·envScore·레짐·이벤트Dn)
cause_text · cause_tags text[] · next_r1 (익일 수익 — 다음날 채점 크론이 기입)
```

과거분 부트스트랩: 정량 features는 10.5년 소급 계산 가능(스크립트). cause 텍스트는 소급 불가 —
가동일부터 축적하되, 대형 사건일(±5% 이상 ~150일)은 1회성 백필로 Claude가 사후 요약 가능.

### 3. 유사 사례 검색 (비계량 아님 — 검색은 정량, 해석이 정성)

- 정량 특징 정규화 거리 top-K(K=5) + cause_tags 일치 가중.
- 임베딩·벡터DB 불필요 — 수치 특징 + 태그로 충분 (표본 수천 일).

### 4. 반영 1단계 — 표시 전용 (판정 불변)

일봉 판정 문자·애프터 문자에 1줄 추가:
`유사사례 5건(급락+외인대량매도+이벤트경계): 익일 평균 +1.2%·상승 3/5 — 대표 2024-08-05(-10.3%→+3.3%)`

### 5. 반영 2단계 — 60일 채점 후 승격 검토

`유사사례 top-K 익일 평균` vs `label_r1` 상관 실측 → 유의하면 환경 점수판 축(클램프 ±1~2)으로
승격. 근거 미달이면 표시 유지 또는 제거 (WTI·FOMC감산 기각 전례).

## 적용 범위 (사용자 결정 필요)

지시엔 "신모델·대가모델의 정규장·애프터장 일봉예측"이 함께 언급됨. 제안: **1단계는
일봉(predict-daily) 문자에만** 적용 — 사례의 단위가 '하루'라 일봉 스윙과 정합. 정규장
분봉 스트림(피셔)은 사례 단위가 달라(분 단위) 오적용 위험 — 승격 검증 후 확장 검토.

## 순서 (구현 시)

① 마이그레이션 + features 10.5년 백필 스크립트 → ② newsRisk 프롬프트 확장(cause) →
③ 검색·문자 라인 → ④ 60일 후 채점 스크립트. 예상 규모: 코드 3파일 + 마이그레이션 1 + 스크립트 2.
