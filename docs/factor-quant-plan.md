# 정성 팩터 정량화 — 야간 정보 기반 당일 진입 근거 (기획)

**사용자 지시 2026-08-08**: "정성적 요인들을 구체적으로 수집·분석해 정량화하고, 전날 야간~새벽까지 수집된 정보로 당일 국장 프리장 또는 정규장에 진입할 상승·하락 근거를 마련한다."

이 문서는 코드 착수 전 기획이다(AGENTS.md 원칙). 단계별로 사용자 확인을 받으며 진행한다.

---

## 0. 출발점 — 오늘 실측이 세운 벽

새 시도가 같은 벽에 부딪히지 않도록 먼저 못 박는다. 2026-08-08 검증 세션 결과:

| 시도한 것 | 결과 |
|---|---|
| 익일 **갭** 방향 예측 | 하닉 동의일(68일)만 유의(p=0.001) · 삼전 무의미(p=0.74) |
| 익일 **시가→종가(r_oc)** 예측 — 11요인 | **10개가 리프트 음수**(추종하면 손해) |
| ↳ 간밤 SOX 추종 | -7 / -8%p |
| ↳ 갭 추종 | -3 / -6%p |
| ↳ 전날 강한 마감 → 롱 | **-13 / -9%p** |
| ↳ **갭 반대(되돌림)** | **+1 / +4%p** — 유일한 양수 |
| ↳ 큰 갭(≥2%) 반대 | 하닉 +1 / **삼전 +8%p**(105일·적중 58%) |

**핵심 교훈 3가지**
1. **간밤 매크로는 09:00 갭에 이미 반영된다.** 그래서 "밤 정보 → 당일 방향 추종"은 구조적으로 진다. 과거에도 같은 결론이 두 번 나왔다(간밤 SOX 게이트 기각·축1 역행 돌파가 더 정확).
2. 그럼에도 **되돌림 방향은 살아 있다.** 새 팩터는 "추종"이 아니라 "과대반응 판별"에 써야 승산이 있다.
3. 일간 방향 적중은 문헌상 52~57%가 현실 상한이다. 이 프로젝트 미너비니가 55.5%로 이미 그 부근이다.

**따라서 이 기획의 목표는 "새 정보원이 기존 가격 팩터가 못 하던 것을 하는가"이며, 1순위 용도는 방향 예측이 아니라 ①과대반응 판별 ②비중 게이트 ③레짐 인식이다.**

## 1. 예측 대상 정의 (무엇을 맞출 것인가)

하나로 정하지 않고 4개를 동시에 채점한다. 팩터마다 유효 구간이 다르기 때문이다.

| 코드 | 정의 | 결정 시점 | 용도 |
|---|---|---|---|
| **T0 갭** | (당일 시가 − 전일 종가)/전일 종가 | 09:00 이전 | 프리장(NXT 08:00~) 진입 판단 |
| **T1 r_oc** | (당일 종가 − 당일 시가)/당일 시가 | 09:00 | 정규장 진입 판단 ★주력 |
| **T2 r_cc** | 전일 종가 → 당일 종가 | — | 일봉 시스템 호환 |
| **T3 r3** | 3일 후 종가 | — | 일봉 스윙(미너비니) 호환 |

**T1이 주력이다.** 갭은 못 잡아도 그 후 흐름은 참고할 수 있다는 사용자 가설이 여기 걸려 있고, 프리장·정규장 진입 결정에 직접 쓰인다.

## 2. 팩터 인벤토리 — 소스 조사 결과

### 2-A. 이미 시스템에 있음 (수집 중)

| 팩터 | 소스 | 주기 | 검증 |
|---|---|---|---|
| 환율 USD/KRW, 미 2Y·10Y, WTI, DXY, TLT | 야후 | 일 | 10Y·DXY만 게이트 채택 |
| 전일 SOX | 야후 ^SOX | 일 | 축1 가중 2 / 게이트는 기각 |
| 외인·기관 수급(종목·코스피 현물/선물) | 네이버 | 일 | 게이트 9종 전부 기각 → 표시 전용 |
| newsRisk 0~10 | 구글뉴스 6질의 + AI | 일 | 22일치·미검증 |
| political score 0~100 | 뉴스 + FRED | 일 | **저장 안 됨** |
| FOMC·CPI·NFP·실적 캘린더 | config + 자동 | 이벤트 | 감산 게이트 채택 |
| 10Y 기대인플레(T10YIE) | FRED | 일 | political에서만 |

### 2-B. 없음 — 새로 확보 (조사 완료)

| 팩터 | 소스 | 접근성 | 주기 | 판단 |
|---|---|---|---|---|
| **DRAM/NAND 현물가·DXI** | DRAMeXchange | **유료** Silver USD 4K/년(일별가+5년 이력+DXI 1년) | 일 | 비용 대비 판단 필요 |
| 〃 대체 | TrendForce DataTrack 공개 차트 | 공개 페이지(스크래핑 필요·API 없음) | 주~월 | 후보 |
| **한국 반도체 수출 10일 단위** | 공공데이터포털 관세청 오픈API | **무료·API·키 필요** | 10일(1·11·21일 발표) | ★**최우선** |
| **반도체 수출물가지수** | 한국은행 ECOS 오픈API | 무료·API·키 필요 | 월 | 채택 |
| 미 반도체 PPI | FRED (PCU334413·WPU117847 등) | **무료·기존 키 사용 가능** | 월 | 즉시 가능 |
| **EPU 정책불확실성** | FRED(미국 일간)·정책불확실성 사이트(한국) | 무료 | 일/월 | ★즉시 백테스트 가능 |
| **GPR 지정학리스크** | Caldara·Iacoviello 공개 | 무료(CSV) | 일 | ★즉시 백테스트 가능 |
| 실적 컨센서스·서프라이즈 | 에프앤가이드·야후 | 유료/제한 | 분기 | 보류 |
| 공매도·대차잔고 | KRX 공개 | 무료(스크래핑) | 일 | 후보 |
| 옵션 풋콜·변동성 스큐 | KRX | 무료 | 일 | 후보 |

**조사 요점**
- DRAM 현물가 **무료 API는 없다.** DRAMeXchange는 연 USD 4K, TrendForce 공개 차트는 갱신 주기가 느리고 API가 없다.
- 대신 **관세청 10일 단위 반도체 수출 실적이 무료·API로 열려 있다.** 한국에서 반도체 업황 선행지표로 실제 널리 쓰이며, 매월 1·11·21일 발표라 **이벤트성 촉매**로도 쓸 수 있다.
- EPU·GPR은 공개 일간 시계열이라 **10년치 즉시 백테스트가 가능하다** — 다른 팩터와 달리 60일을 기다릴 필요가 없다.
- ⚠2026년 현재 메모리 공급 부족 국면(2024~ 진행)이라 수출물가가 전년비 큰 폭 상승 중이다. 팩터 해석 시 레짐을 감안해야 한다.

## 3. 단계별 실행 계획

### Phase 0 — 저장 인프라 (즉시, 60일 시계 시작)
- `predict_factor_days` 신설: date, symbol, 팩터별 원값·정규화값·방향·강도, 소스, 수집시각
- 기존에 계산만 하고 버리던 것부터 연결: **political score/newsScore/macroScore/drivers**, 축1 C3~C9 각 방향·강도, 수급, 이벤트 플래그
- 하루 1행 upsert, 크론 편승(장 마감 후 + 05:10 미장 마감 후 2회)
- **이것이 선행조건이다. 저장이 없으면 어떤 가중치도 검증할 수 없다.**

### Phase 1 — 즉시 백테스트 가능한 것 (같은 주)
- EPU·GPR·미 반도체 PPI를 10년치 받아 T0~T3 리프트 단변량 검정
- 채택 기준은 기존과 동일: **2종목 × 3구간(전체/3년/1년) 무해 + 개선**
- 여기서 통과하는 게 있으면 즉시 게이트 후보

### Phase 2 — 신규 수집 (사용자 키 필요)
- 관세청 10일 수출: 발표일(1·11·21일) 전후 T0~T3 반응 측정 + 증감률의 레짐 지표화
- 한국은행 ECOS 수출물가(월)
- (선택) DRAMeXchange 유료 — Phase 1·2 결과를 보고 비용 판단

### Phase 3 — 정성 판단 채점 (60일 후)
- political·newsRisk의 리프트 검정
- ⚠**선결 과제: 점수 분산 확보.** 현재 newsRisk가 22일 내내 2~6에만 몰려 있어 상관 측정이 불가능하다. 프롬프트에 앵커(평상시 3, 이례적일 때만 7+)를 넣어 분산을 만든다.

### Phase 4 — 결합·점도표
- 통과한 팩터만 가중 결합. **가중치는 리프트 크기 비례**(감으로 매기지 않는다)
- 워크포워드: 앞 절반으로 가중치 산출 → 뒤 절반으로 검증
- 산출물: 1~10점 스코어 + 요인별 점도표(검증됨/미검증 색 구분) + 웹 화면 + 문자 1줄
- **미검증 팩터는 종합 점수에 넣지 않고 별도 열로만 표시**
