# F-Low 설계 문서 — 금요일 완화 등급 (등록 보류)

> **상태: 설계까지만. 헌법 개정안 등록·발효 금지** (발주서 WORKORDER_MT_v04 §5·§7).
> 등록·발효는 발주자 별도 승인 사항이며, **E-체계 재확인과 분리**한다(동시 개정 금지).
> 이 문서는 승인 시 그대로 개정안으로 옮길 수 있도록 조건·수치·채점까지 확정해 둔 초안이다.

- 작성 2026-08-15 · 근거 스펙 `specs/SPEC_MT_v04.md` · 참조 헌법 `g1br/constitution/amendment_2026-08-12_event_grades.md`
- 대응 현행 규칙: G1A `lib/g1a/score.ts` — `weekday === 5 → "보류2 금요일(주말 보유 금지)"` (점수보다 우선하는 무조건 보류)

---

## 1. 무엇을 바꾸자는 것인가

현행 금요일은 **점수와 무관하게 무조건 보류**다. 근거는 "주말 뉴스 리스크를 안고 잘 수 없다"는 것이며, 이는 방향 판단의 실패가 아니라 **보유 기간 리스크**에 대한 규칙이다.

F-Low는 그 규칙을 없애지 않는다. **MT가 강한 순방향일 때에 한해** 평시 Low의 1/2, E-Low와 같은 **1/12** 크기만 허용하는 예외 등급을 둔다. 사이징으로 리스크를 흡수하고, 방향 근거는 MT라는 독립 증거로 보강한다는 구조다.

## 2. 발동 조건 (전부 충족해야 함)

| # | 조건 | 값 | 근거 |
|---|---|---|---|
| ① | 요일 | 금요일 (weekday = 5) | 대상 한정 |
| ② | T2 방향 확신 | GapScore 절대값 ≥ **High 문턱** | E-Low와 동일 눈높이 (평시 Low보다 엄격) |
| ③ | **MT 순방향** | `sign(MT) === sign(GapScore)` | 독립 증거의 일치 |
| ④ | **MT 강도** | `|MT| ≥ 0.5` (= 스펙 §3.1 "강") | "강한 순방향"의 조작적 정의 |
| ⑤ | MT 국면 정합 | 상방이면 `P(S1) + P(S2) ≥ 0.6`, 하방이면 `P(S3) + P(S4) ≥ 0.6` | 톤과 국면이 따로 노는 밤 배제 |
| ⑥ | 다른 보류 사유 없음 | 보류1·3·4·5·7 중 어느 것도 아님 | 금요일(보류2)만 면제한다 — **다른 보류는 그대로 유효** |
| ⑦ | 이벤트 밤 아님 | 보류1 미해당 | E-체계와 **중첩 금지** (F-Low와 E-Low 동시 적용 불가) |
| ⑧ | 유동성 | `liquidity !== "hold"` | 현행 실행 요건 승계 |

## 3. 사이징·실행

- 크기 **1/12** (평시 Low 1/6의 절반, E-Low와 동일). 상향 없음.
- 사이징 절대 상한(1/3)·물타기 금지·luck 분류 **불변** — 헌법 §4 승계.
- 삼전·하닉 동시 F-Low 발동 시 **합산 1/12** (둘 중 |GapScore| 큰 쪽만). 금요일에 노출을 두 배로 만들지 않는다.
- 청산: 월요일 R1이 평시와 동일하게 판정. F-Low 전용 청산 규칙은 두지 않는다.

## 4. 채점 (승격 심사 2지표 — E-섀도 방식 승계)

1. **F-Low 발동 밤의 가상 손익** — 진입가(금요일 19:40 NXT) → 월요일 시가. 누적이 음수면 즉시 폐기.
2. **쉰 대가와의 비교** — 같은 조건에서 F-Low를 쓰지 않았을 때(=현행 보류)의 기회비용. F-Low가 이겨야 존치.
- 보조: 주말 뉴스 충격 밤(월요일 |갭| ≥ 2σ)에서의 F-Low 밤 비율 — **꼬리 위험이 실제로 커지는지**를 따로 본다.

## 5. 발효 전 필수 선행 조건

| 선행 | 상태 (2026-08-15) |
|---|---|
| MT 사다리 **3단계(게이트) 통과** | ✗ — 1단계(표시)에 있음 |
| 60일 백필 ⓓ 관문 통과 | ✗ — **판정 불가/미통과** (`docs/mt-backfill-60d.md`) |
| MT 전환 선언 3년 성적 | ✗ — 미달 (`docs/mt-retro-3y.md`). 단 F-Low는 **전환 선언이 아니라 톤 값**만 쓰므로 이 항목은 결격 사유가 아니라 주의 사항 |
| 금요일 표본 | 60일 구간 금요일 ≈ 12밤 — 채점에 부족 |
| E-체계 재확인 | 별건 — **동시 개정 금지** |

**결론: 현재는 발효 조건을 하나도 충족하지 못한다.** 이 문서는 조건이 갖춰졌을 때 논쟁 없이 등록할 수 있도록 미리 확정해 두는 용도다.

## 6. 등록 시 문안 (개정안 초안 — 승인 전까지 등록 금지)

```
G1A §5.6 보류2 개정안 (F-Low):
  금요일은 원칙적으로 보류한다. 다만 아래 ①~⑧을 모두 충족하는 밤에 한해
  1/12 크기의 진입을 허용하고, 이를 F-Low 등급으로 기록한다.
  F-Low는 E-등급과 중첩 적용하지 않으며, 사이징 절대 상한·물타기 금지·luck 분류는 불변이다.
  발동·미발동 밤은 모두 채점하며, 발동 밤 가상 손익 누적이 음수가 되면 자동 폐기한다.
```
