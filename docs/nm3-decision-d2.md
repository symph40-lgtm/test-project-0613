## 결정 1 — 이벤트 달력 거버넌스: **구현자 제안 승인 + 미승인 폴백 추가**

- **주체**: 발주자. **절차**: 분기 초 시스템이 공개 일정(FOMC·CPI 캘린더, NVDA/AVGO/TSMC/MU 실적 발표일, 트리플위칭)에서 갱신 초안을 생성해 문자 발송 → 발주자 승인 회신으로 확정. 자동 확정 금지 (헌법상 인간 항목).
- **미승인 폴백 (신설)**:
  1. 분기 개시일까지 미승인 시: 미승인 초안을 조용히 사용하는 것 **금지**, 달력 공백을 조용히 두는 것도 **금지**
  2. 리마인더 문자 반복 발송 (승인 시까지)
  3. 해당 기간의 밤들은 채점에 **`calendar_unverified` 태그**로 명시 기록 — 승인 후 소급 분류
- 근거: 인간 항목의 취지 보존 + 태그 수집의 결측 편향 방지. 트랙 B(R3) 활성 전까지는 측정에만 영향.

## 결정 2 — L_max: **수치 확정 보류, W3-1 선행 + 결정 기준 사전등록**

숫자를 실측 확인 후 고르는 재량을 차단하기 위해, **W3-1 결과를 보기 전에** 아래 선정 기준을 등록한다.

**선정 기준 (사전등록)**:
1. **경제성 하한**: 국장 진입이 차단·감산되는 날 ≤ 전체의 25% (현행 명목합 3.0x의 162/245일 차단은 이 기준으로 자동 탈락)
2. **꼬리 목표**: 실측 결합 최악일 손실이 계좌 기준 목표 상한 이내 (상한 수치는 W3-1의 상관표 확인 전, 실행 직전 등록)
3. **후보 3안 동일 잣대 평가**:
   - (a) 명목 합산 L_max ∈ {3, 4, 5}
   - (b) 상관 가중 합산
   - (c) **이월 헤어컷** — 1박 보유분을 명목 3x가 아니라 국장 시간대 실측 변동 기여율로 할인 계상 (예: ×0.4 상수)

**사전 선호 기록**: (c) 헤어컷 방식. 근거 — 1박 SOXX는 국장 시간대 신규 의사결정이 없는 정적 포지션이며 실제 리스크 기여는 미 선물 경로의 실측 공분산만큼이므로, 명목 합산은 과대계상(현행 충돌의 원인). 리스크 기준 계상이 전문 운용 표준. 단 헌법 단순성을 위해 헤어컷 계수는 W3-1에서 1회 산출 후 **상수 고정**, 분기 재검토 항목으로 등재. 이 선호는 기록일 뿐이며 최종 선택은 기준 1·2의 실측 통과 여부로 판정 — 선호가 기준을 이기지 못한다.

**한도 도달 시 동작**: 이진 차단이 아니라 **감산 우선** — 정찰 단부터 축소, 상한 초과분만 차단. (R2의 목적은 매매 금지가 아니라 상관 노출의 상한)

## 결정 3 (부수) — 스펙 작성 규칙 추가

"전야 23:00"(D-2 과정 발견)과 "국장 0.01% 반영"(D-1 정정)의 반복으로 패턴 확정. 스펙 작성 규칙에 추가:

> **타 시스템의 시각·상수·경로를 인용할 때는 코드/DB 출처를 병기하고, 출처 미확인 값은 '추정'으로 명시 표기한다.** 출처 없는 단정 표기는 리뷰 리젝 사유.

## 착수 지시

- **W1(V5) 즉시 착수** — 최우선. 이후 W2 → W3-1 → W4 순 (W4는 병렬 가능)
- W2는 **사전등록 커밋(삼전 E1 "비용 후 양수 유지" 예상 포함)이 재심 실행보다 선행**함을 파이프라인 타임스탬프로 확인
- W3-1 산출물(상관표·동시 노출 분포·후보별 차단 일수·헤어컷 계수) 수령 후 결정 2의 기준 1·2로 L_max 확정 → D-3에 기록
- 이벤트 달력 초안 1회차: 차기 분기 개시 전 발송
