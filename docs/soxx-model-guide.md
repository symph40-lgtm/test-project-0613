# SOXX 신모델 가이드 — 창1+F 통합 사양 (v2)

작성 2026-08-06 · 기준 커밋 03d705e · 문서 쌍: soxx-model-guide.docx (동일 내용 Word판)

## 1. 개요 — 무엇을 하는 모델인가

- **판정 대상**: 미국 반도체 ETF **SOXX** (실매매는 상방 **SOXL**·하방 **SOXS**, 3배 레버리지)
- **하루 리듬**: 프리장(20:00 KST~)에서 첫 신호 → 정규장 개장(22:30 KST) 후 심판 → 비이견일은 1박(다음날 22:30 시가 청산), 이견일은 종가(MOC) 청산
- **성능(246일 백테스트)**: 누적 **+141.6%p** (SOXX 기준 · 3x 계좌 환산 일당 약 +1.7%) · 최악일 -4.08% · 스탑 컷 32일(13%)
- **운영**: 크론이 매분 감시, 모든 행동은 실전(신모델)·SOXX 문자가 정량 지시. 웹 확인 = /newmodel

## 2. 판정 엔진 — 두 개의 신호와 역할 분담

| | 창1 (모멘텀) | F (피셔) |
|---|---|---|
| 봉 | **1분봉** 6봉 누적 순전진 | **5분봉** (OR 3봉·확인 1봉) |
| 창 | 정규장만 (09:30 ET 게이트) | 프리장 07:00 ET(20:00 KST)부터 + **0930 재박스** |
| 문턱 | 6봉 전진 ≥ 평소 흔들림(30봉 평균폭×0.5)×5 | 기준 박스 ± 오프셋(10일 평균폭의 5%) 이탈 마감 |
| 역할 | 속도 담당 — 컷률 6%로 더 정확 | 검증·선행 담당 — 프리장을 먼저 봄 |

- 파라미터는 3축 격자 실측으로 닫힘: F 1분봉화(-27~-39%p)·확인 2~3봉(-3~-5)·10/15분봉(-11~-14) 전부 열위 → **5분봉·확인 1봉이 국소 최적**
- 0930 재박스: 프리장 박스를 정규장 진폭에 맞게 09:30~45 박스로 교체(상태 승계) — +3.4%p

## 3. 규칙 세트 (수정안 — 확정)

1. **진입**: 먼저 온 신호 방향으로 100%. F 프리장 확인이면 **확인가로 즉시 매수**(개장가 대기 대비 +10.7%p). 문자 제목에 판정 주체(F/창1) 명시
2. **프리장 무스탑**: 개장 전에는 자동스탑설정 안 함(전 폭 실측 열위) — **이 구간 실측 최대 손실 SOXL/SOXS 기준 약 -5.0%**(SOXX -1.67%, 57일 최악치). 개장 직후 자동스탑설정 SOXX -2%(ETF 약 -6%)
3. **E1 심판 (F 선행일)**: 창1이 F와 **반대**로 서면 전량 청산+창1 방향 100% 역진입 — "나중 신호가 심판" (+36.2 vs 심판 없음 +8.7, 59일)
4. **수정안 (창1 선행일)**: F가 반대여도 낮에는 행동 없음(보유·스탑만) — F 반대의 가치는 **1박 금지 문지기**뿐 (+5.1%p, a24f012)
5. **1박**: 자격 = **비이견일**(동의+무판정 — F확인 ≥ 창1, 동시각 포함). 다음 세션 22:30 시가 전량 매도. **밤 구간 자동스탑설정은 재난선 SOXX -5%(3x -15%)** — 낮 폭을 밤에 두면 애프터 급락·회복 경로에 컷(8/5 실사고)
6. **이견일**: 1박 금지 — 취침 전 보유 전량 **MOC(종가) 매도 예약** (접수 마감 04:40 KST)
7. **인버스 이익 보호**: SOXS 레그가 미실현 **+1%** 도달 후 저점 대비 **0.9% 반등**하면 즉시 전량 매도 (09:30~10:30 ET 창) — 기브백 33일 중 26일이 인버스 진입일 (+14.4%p·최악 -4.08). **레버(SOXL)에는 미적용** — 보유가 정답
8. **창2(재점화)·창 반대 점화**: 규칙 아님 — 창의 정보는 그날 첫 판정뿐

## 4. 하루 흐름 (ET · 한국시간 병기)

| 시각 | 일어나는 일 |
|---|---|
| 04:30 ET (17:30 KST) | 모니터 시작 · 프리장 개시 브리핑 문자 (시세·갭·1박 보유 안내) |
| 07:00 ET (20:00 KST) | F 창 개시 — 이후 F 확인 시 "진입 — F(피셔) 판정" 문자 → 확인가 즉시 매수 |
| 09:30 ET (22:30 KST) | 정규장 개장 — 자동스탑설정(-2%) · 전일 1박 있으면 시가 청산 문자 · 창1 판정 |
| ~09:45 ET | 창1 동의 → "1박 자격" / 반대 → "전환" 문자 (E1) |
| 09:30~10:30 ET | 인버스 이익 보호 감시 창 |
| 10:30 ET (23:30 KST) | 취침 지침 문자 — 동의일 무행동 1박(재난선 -5% 변경) / 이견·무판정일 MOC 예약 |
| 16:00 ET (05:00 KST) | 종가 — 결산(이메일) · 1박이면 보유 지속 |
| 07:00 KST~ | 아침 요약 문자 (00~07시 이벤트 합산) · 11:00 발송 점검 문자 |

**실사례 (8/5 세션)**: 08:04 ET(21:04) F 하락 확인 → SOXS 진입 → 09:30 ET(22:30) 창1 상승(개장 5분 +0.7% 급등) = 이견 → 09:31 전환 문자(SOXS 매도·SOXL 매수) → 09:50 ET 고점 +2.0% → 되밀림 → 이견일 규칙으로 종가 청산.

## 5. 문자 체계 — 받으면 무엇을 하는가

| 문자 | 액션 |
|---|---|
| 진입 — F/창1 판정 | ①해당 ETF 100% 즉시 매수 ②(프리장이면) 스탑은 개장 후 ③다음 문자 대기 |
| 전환 — 창1이 F와 반대 | ①보유 전량 매도 ②반대 ETF 100% 매수 ③새 자동스탑설정 |
| 동의 확인 (1박 자격) | 행동 없음 — 보유 유지, 취침 시 무행동 1박 |
| F 이견 | 보유는 유지 — 오늘 1박 금지, 취침 전 MOC 예약 |
| 이익 보호 청산 (인버스) | 보유 SOXS 전량 즉시 매도 |
| 스탑 도달 | 자동매도 체결 확인만 — 재진입 없음 |
| 취침 지침 (23:30 KST) | 동의일: 재난선 -5%로 변경 후 취침 / 그 외: MOC 예약 |
| 1박 청산 (22:30 KST) | 보유 전량 시가 매도 |
| 세션 전환 예고 (전환 10분 전 4회) | 레그별 현황·지침 확인 — 급등 시 재량 익절 선택지 |
| 결산·아침 요약·발송 점검 | 정보 — 행동 없음 |

- 시간 정책: **한국 00:00~07:00 SMS 금지**(이메일+아침 요약 대체) — 세션 전환 예고(04:50)만 예외
- 모든 액션 문자는 정량(가격 숫자·수량·주문유형·시각) + 판정 주체 명시

- 리스크 요약: 최악일 -4.08%(3x -12%) · 컷 13% 빈도 · 프리장 무스탑 구간 실측 최대 -1.67%(3x -5%)

## 8. 운영·검증 장치

- **웹**: /newmodel — 지금 할 액션·오늘 문자 타임라인·채점 누적 (로그인 필요, 홈 메뉴 ★)
- **채점 4열**: p(주기준) · pNP(보호 없음) · pRe(역진입판) · pV0(무rebox) — 60일 페이퍼 궤도(일당 +0.58% SOXX) 안이면 유지, 이탈 시 재검
- **parity**: scripts/soxx-v2-parity.ts — 라이브 산식 = 백테스트 완전 일치 확인 (수정안 +114.4 → 최종 +141.6 체인)
- **발송 점검**: 매일 11:00 문자 — 판정 기록 vs 실제 발송 대조·누락 원인
- **데이터 축적 중(추후 판정)**: 밤 분봉 BAQ(밤 조기청산 규칙), 저녁 신호 캐시(60일 후 재검), 조기 프리장(역방향 가설)
- **10일 평가**: 8/17(월) 11시 — 신모델 vs 기존 피셔 계층 비교 문자

## 9. 용어 (쉬운 말)

- **창1**: 직전 6분간 한 방향 순전진이 평소 흔들림의 몇 배인지로 추세 시작을 잡는 모멘텀 판정
- **F(피셔)**: 시초 15분 박스를 오프셋만큼 벗어나 마감하면 추세로 인정하는 돌파 판정
- **E1 / 심판**: 두 신호가 반대일 때 나중 신호를 따르는 규칙
- **비이견일 / 이견일**: 두 신호 방향 일치(또는 한쪽 무판정) / 반대 — 1박 허용 여부를 가름
- **1박**: 당일 청산하지 않고 다음 세션 시가에 파는 것 — 밤 갭이 수익원
- **재난선**: 밤 구간 전용 넓은 스탑(-5%) — 통계 밖 붕괴만 차단
- **MOC**: 장 마감 단일가(종가)에 무조건 체결되는 예약 주문 (접수 마감 04:40 KST)
